# BF のあとの直し（2026-11-05 ユーザー指示）：機械の塔の扉の色を遠くから分かるように・上り階段・足もとの光をやめる

ブランチ `bg-tower-glow`（main に取り込む・**公開はしない**）。BF のあとのユーザーの3つの指示。

## 1. 扉の色を遠くからでも分かるように

- 扉・スイッチの「自分で光る部分」（赤・青のランプと光のふち）だけを取り出した絵 `*_glow.webp` を作った（`python3 -I tools/art/machine_tower_art.py`。
  赤・水色の強い所と、そのとなりの白く光る芯だけ。真ちゅうの金色は入れない）
- それを **暗さの層（drun__light）の上の層**（雷の高原の予告の印と同じ層 `#thunderLayer`）に重ねる。明かりの外（前に見たマス）でも暗くならない
- 扉のマス・スイッチのまわりに、その色のうすい光のにじみ（開いている扉・閉じている扉どちらも。スイッチは今開いている色）
- 見たマスだけ出す（まだ見ていない扉の場所は分からないまま）。スイッチを押したときは光もゆれる
- 絵の置き方・大きさは扉・スイッチの絵と同じ（`src/ui/styles/dungeonRun.css` の `.drun__lamp`）

## 2. 上り階段

- 塔では、階段の上で「上りますか？」と聞く窓の絵を上り階段の絵（`machine_stairs_up`）に（正方形なので幅 150px）
- 写真で確かめると、主人公が階段の上に乗ると体で階段がほとんど隠れて分かりにくかったので、**塔の階段のマスにうすい金色の光とふち**を足した（ゆっくり明るさが変わる。暗さの上の層）

## 3. 開いた扉の足もとのうすい光（BD で足したもの）はやめた

## 確かめ

- テスト `tests/bdMachineTower.test.ts`（光の絵がある・光の層・階段の光・上り階段の絵・足もとの光が無い）
- 写真の道具 `tools/e2e/bd_tower_shot.cjs` に、明かりの外の扉（扉から3〜5マス離れた所）・階段の上に乗ったとき・上るか聞く窓を足した
- 全部まとめてテストすると、時間切れで落ちるテストがある（`pukarim`・`kalshell`・`lazuck` の3つ。今回の変更の前の main でも同じ）。1つずつ・制限時間を長くすると通る

## 要確認

1. 光のにじみの強さ・大きさ（にじみは直径 104px・いちばん濃い所で 34％）
2. 階段の金色のふちはゆっくり明るさが変わる（動きを減らす設定では止まる）

## 2回目の直し（2026-11-05 ユーザー指示。ブランチ `tower-glow-fix2`）

ユーザー確認：窓の絵・足もとの光を消した件・光の強さ・ふちがゆっくり明るくなる件は今のままで OK。そのうえで2つ。

1. 赤の状態と青の状態が遠くから区別できなかった → **開いている色の扉だけ**ランプと光のふちを強く光らせ、まわりに光のにじみ（直径 120px・いちばん濃い所で 50％）。
   **閉じている扉**はランプをごく弱く（18％・にじみなし）、扉の絵も暗く・色をうすく（明かりの外は明るさ 32％、明かりの中は 60％）
   - 1・2階の飾りの赤の扉も、赤の状態で赤く光る・青の状態で暗いことを写真で確かめた
   - 写真の道具は、赤の扉と青の扉が両方とも画面に入る所に立つようにした（1階・3階のこのシードでは両方が入る所が無く、片方の色だけ写る。5階は両方）
2. 階段がふちの金色の床にしか見えなかった → 塔の階段のマスは、**上り階段の絵を暗さの上に大きめ（56×58px）に出し、上に金色の上向きの矢印**（ゆっくり明るさが変わる）。金色のふちはやめた。まわりのうすい金色の光はそのまま
