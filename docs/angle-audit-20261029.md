# 絵の角度の点検（2026-10-29 夜。指示書 D）

ユーザーの iPhone の点検（ZIP「Mistral_Fixes_20261029_night」の写真 07 石の橋・08 ベンチ・09 排水溝）。
街と建物は「真上より少し手前から見下ろす正面向き」。ななめ上から見た角度（正面と横の面が両方見える）や遠近（手前が大きく奥が小さい）の部品を全部さがした。

- 見方：部品の絵を1枚ずつ並べて見た（街の部品・地面に描く部品・部屋の床と壁・部屋の家具）。写真は作業報告書（ZIP）に入れた
- ○＝正面向き　△＝少しななめ（側面の厚みが少し見えるだけ）　×＝ななめ・遠近
- 外したもの（×のうち、外しても入口・道・調べる所がなくならない物）は `tools/design/town2026_build.py` の `ANGLE_OFF`（もとの置き場所は PROPS に残してある。新しい絵が届いたら `ANGLE_OFF` から外すだけで戻る）
- 依頼文は `docs/design-requests-20261030/`
- **2026-10-30（指示書 H）**：依頼文 01〜07 の正面向きの絵 14枚が届き、全部入れた（原本 `design-parts/town-20261028/front-facing-20261030/`）。
  外していた物はもとの置き場所に戻した（`ANGLE_OFF` は空）。下の表の「角度」「扱い」は入れたあとの状態。前の状態は「前」の列

## 3. 部屋の家具（描き直し待ち）

部屋（主人公の家・となりの家・住人の家・研究所・管理局・練習場・大会会場・花屋・仕立て屋・カードショップ）は、床と壁の絵そのものが
「奥の壁は正面・左右の壁はななめに見える」作り（部屋の形の遠近）になっている。左右の壁ぞいの家具は、その壁の向きに合わせてななめに描かれている。
外すと部屋の多く（カードショップはほとんど全部）がなくなり、C1 で直した棚の飾りのカードも消えるので、部屋の家具は外していない。

**決定（2026-10-29 深夜。指示書 G）**：ユーザーは「外して正面向きに描き直す」を選んだ。ただし進行の判断で、**描き直しの絵が届くまでは今のまま残す**
（外すとカウンターなどがなくなり、店が使えなくなるため）。
- 部屋の家具は外さない。外した街の部品（ベンチ・排水溝・木箱・花壇。`ANGLE_OFF`）はそのまま
- 部屋の依頼文はまだ作らない（どこまで描き直すかを進行のチャットで決めてから）

**決定（2026-10-30。ユーザー）**：部屋は**床と壁も含めて正面向きに描き直す。まずカードショップから**（デザイン担当に依頼中）。
**絵が届くまで、今の家具（と床・壁）はそのまま**。届いたら、カードショップの部屋（`tools/design/cardshop_v2.py`）から入れ替える。
