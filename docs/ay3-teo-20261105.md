# テオの3枚コンボの見せ場（2026-11-05 ユーザーの指示。AY2 の採用案が土台）

ブランチ `ay3-teo`（main に取り込む・**公開はしない**）。コンボの数字・条件は変えていない。ライフは 1.60 のまま。

## 足したこと（ユーザー指示の2つだけ）

1. **α・β・γ を探す**（`ai.ts` の `chooseOverdriveDig`。テオの構え overdrive だけ）：α・β・γ のどれかを手札に持っていて、残りが手札に無いとき
   - システムチェンジ：α・β・γ でも守りでもない札（必要マナのいちばん多いもの）を山札に戻して1枚引く（先に考える。1枚引けるため）
   - システムチェック：チェンジが無いとき。山札の上に手札に無い α・β・γ があると分かったら、山札の上が変わるまで（次の手番まで）1種類でも取っておく（`peekShowsMissing`）
2. **最初の手札に α・β・γ のうち1枚を必ず入れる**（ボスだけの決まり。`OpponentDefinition.openingAny`→ `createBattle` の `openingAny`）。シャッフルしたあと、いちばん上に近い1枚を山札のいちばん上へ動かすだけ（山札の枚数は同じ）

## 結果（目安のプレイヤー A・3箱 × 1000回。`docs/design/ay3-teo-20261105/`）

| 組み合わせ | 勝つ割合（13±3） | 山札切れ（25 以下） | コンボの対戦（目安 5〜10） |
| --- | --- | --- | --- |
| AY2 の採用案（土台） | 14.4 | 9.8 | 0.3 |
| **＋探す＋最初の手札（採用。システムチェック 0枚のまま）** | **15.5** | **11.6** | **0.3** |
| ＋探す＋最初の手札・システムチェック 2枚に戻す | 21.0 | 14.9 | 0.4 |
| ＋1種類でもマナにしない（指示の外）・チェック 0枚 | 24.6 | 14.6 | 0.4 |
| ＋1種類でもマナにしない（指示の外）・チェック 2枚 | 34.1 | 18.9 | 0.6 |

- 優先の2つ（勝つ割合・山札切れ）は採用案で目標に入った（デッキは AY2 のまま。直す必要がなかった）
- **コンボの対戦は 0.3％ のまま上がらなかった**。調べたこと（60対戦）：
  - テオの手番のうち α・β・γ が1種類だけのことが多く（463回）、2種類は 81回、3種類そろうのは 5回だけ（そのうち4回はマナが足りない）
  - 1種類だけのうちは取っておかない決まりなので、探している間にその1枚をマナにしてしまう（185回）。最初の手札に入れた1枚も多くはマナになる
  - ギアロスが先に倒されている手番も多い（180回）
- テオのデッキはシステムチェックが0枚（AY2 で減らした）なので、探すのはシステムチェンジ（2枚）だけ

## 要確認

- コンボを上げるには、少なくとも「1種類でも探している1枚はマナにしない」が要りそう（ただしそれだけでは 0.4〜0.6％ で、テオも弱くなる）。α・β・γ の枚数（2枚）・取っておく決まり・コンボの条件のどれかを変えないと、目安の 5〜10％ には届かない見込み
