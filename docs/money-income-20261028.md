## 2. 1勝ごとのお金

- `src/game/dungeon/run.ts` の `winRunBattle`：バトラー・見えない番人に勝ったその場で所持金に入れる（`coins` に入った額）
- 幸運のコインで技カードを選ぶ勝ち（`winRunBattleChoosing`）も同じだけ入る
- 報酬の窓：「勝利！ 技カード「○○」を手に入れた。＋20G」（`dungeonRun.winCoins`）。幸運のコインは選んだあとの窓に「＋20G」

## 3. 宝箱の中身（【仮】）

- 割合などは `economy.ts` の `CHEST_RULES`：お金 70％・道具 25％・技カード 5％
  - お金：表の範囲から 5G きざみ
  - 道具：たいまつ・魔除けの香・煙玉・帰還の羽根から同じ確率で1つ。所持の上限（9）のときはお金に替える（「たいまつはもう持てないので、お金に替えた。」）
  - 技カード：そのダンジョンのボスの切り札のモンスター（`dungeons.ts` の firstClearCards のモンスターカード）の技から1枚（`bossTrumpSkills`）。
    遺跡・森は仮のジオル・仮のフルーネ、水の神殿はミュロル、氷の洞窟はカルシェル、炎の火山はガウル、機械の塔はラズック、天の聖域はソラモ
- 中身は開けたときに `rollChest(ダンジョン, 挑戦の種 seed, 宝箱の ID)` で決める（同じなら必ず同じ。セーブとロードで選び直せない）
- `openRunChest(save, 宝箱の ID)` が中身を手に入れる。技カードは勝ってもらった技カードと同じ扱い（`run.gained` に入れる。3回負けて戻されたら失う。封印の小箱で守れる）
- 画面（`dungeonRunScreen.ts` の `#openChest`）：お金＝袋の絵、道具＝その道具の絵の小窓、技カード＝カードの絵（勝ってもらったときと同じ）

## 4. ボスのお金

- `winRunBattle` のボス：表の初回・2回目から。初回のモンスターカードはそのまま
- 固定のダンジョン（`src/game/progress/dungeon.ts` の `defeatEnemy`）：新しく選んで入ることはもう無い（ダンジョン7つはすべてランダム生成）が、
  前のセーブの途中から続けたときだけ通るので、同じ表の値にそろえた

## 5. 変えていないこと

- 3回負けて戻されても、お金・道具はなくさない（なくすのはこの挑戦で手に入れた技カードだけ）
- 大会の賞金・はじめの所持金 300G

## 6. 目安（テスト `tests/moneyIncome.test.ts` の中で計算。200 回の平均）

水の神殿を1回まわったとき（ボス2回目）：4階・バトラー 12人・見えない番人 8人・宝箱 8つ。

- 全部と戦って全部開けたとき：勝ち 400G ＋ 宝箱のお金 約173G ＋ ボス 150G ＝ **約 723G**
- 見えない番人は近づいたときの抽選で出るので、全部とは戦わないことが多い（半分なら −80G で約 643G）。宝箱の道具（25％）は、お金でなく道具として入る
- 進行の見込み（約500〜600G）より少し多め
