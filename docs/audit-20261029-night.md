# ゲーム全体の点検と直し（2026-10-29 夜）

ユーザー指示（チャット。iPhone の写真3枚つき）。進み具合をここに書きながら進める。カードの数字・ルール・承認した絵は変えない。

## 決まり（「直った」かの判断）

- 壁・石垣・柵・生け垣：1列にまっすぐ。同じ列の部品は高さ・上のふちをそろえ、段差を作らない。継ぎ目は同じ間隔。曲がる所は直角
- 橋：縦横の比を変えて引きのばさない。はしと道・石垣がすき間なくつながる。直せなければ絵の依頼文へ
- 小物：1種類の地面の上に全部のる。ベンチは道・広場のふちと平行で、座る面を道・広場へ。物どうしが重ならない。入口・道・階段をふさがない
- 当たり：絵で物がある所は歩けない・床は歩ける。足が家具・石垣の上に重ならない。後ろに回ったときの前後が正しい。入口はすべて入れて出られる

## 点検の道具

- `tests/walkAudit.test.ts`：街・部屋すべて（12か所）で、入ったときに立つ所から出入口・調べる物・人に行けるか、とじこめられた床が無いか
- 当たりの網目を重ねた写真：部屋は絵の部品を重ねて歩けないマスを赤くする（スクラッチの room_overlay.py）、街は `town2026_build.py` の確認画像、ゲームの中は `?qa=1&hit=1`
- `town2026_build.py` の `check_props`：小物が道の上にはみ出していないか・ほかの小物と重なっていないかに、「石畳と芝生にまたがっていないか」を足した
