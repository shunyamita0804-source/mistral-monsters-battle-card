# ゲーム全体の点検と直し（2026-10-29 夜）

ユーザー指示（チャット。iPhone の写真3枚つき）。進み具合をここに書きながら進める。カードの数字・ルール・承認した絵は変えない。

## 決まり（「直った」かの判断）

- 壁・石垣・柵・生け垣：1列にまっすぐ。同じ列の部品は高さ・上のふちをそろえ、段差を作らない。継ぎ目は同じ間隔。曲がる所は直角
- 橋：縦横の比を変えて引きのばさない。はしと道・石垣がすき間なくつながる。直せなければ絵の依頼文へ
- 小物：1種類の地面の上に全部のる。ベンチは道・広場のふちと平行で、座る面を道・広場へ。物どうしが重ならない。入口・道・階段をふさがない
- 当たり：絵で物がある所は歩けない・床は歩ける。足が家具・石垣の上に重ならない。後ろに回ったときの前後が正しい。入口はすべて入れて出られる

## 点検の道具

- `tests/walkAudit.test.ts`：街・部屋すべて（12か所）で、入ったときに立つ所から出入口・調べる物・人に行けるか、とじこめられた床が無いか
- 当たりの網目を重ねた写真：部屋は絵の部品を重ねて歩けないマスを赤くする（スクラッチの room_overlay.py）、街は `town2026_build.py` の確認画像、ゲームの中は `?qa=1&hit=1`
- `town2026_build.py` の `check_props`：小物が道の上にはみ出していないか・ほかの小物と重なっていないかに、「石畳と芝生にまたがっていないか」を足した

## 点検のしかたと結果（数字）

- 街・部屋 12 か所：`tests/walkAudit.test.ts` で、出入口・調べる物・人すべてに行ける・とじこめられた床なし（すべて合格）
- ダンジョン7つ：もとからあるテスト（`tests/dungeons7.test.ts` など。種をかえて全部の階で、階段・ボス・バトラー・宝箱・スイッチに行ける）に加え、
  種3つ × すべての階の始まりの場所の写真を `tools/e2e/dungeon_audit.cjs` で撮って見た（ダンジョンはマス目ごとに絵を置くので、絵と当たりは同じ）
- バトル：`tools/e2e/battle_audit.cjs` で、オートで3つの相手と最後まで対戦し、0.5 秒ごとに「押せる所が 44 より小さい」「文字が切れている」「説明の枠の文字どうしが重なる」を調べた。
  直したあとに残ったのは「場のカード（76×24）」だけ。これは見えない押せる所を上下にのばしてあり（44px）、実際には押しやすい（下の表）

## 直していない所・理由

| 場所 | 見つけたこと | 直していない理由 |
| --- | --- | --- |
| 街・木の橋 | 欄干の柱と両はしが少し曲がって見える | 今の部品はななめの橋の絵しかなく、まっすぐにするには絵をずらすしかない。縦横の比は変えていない。新しい絵が要る（依頼文 01） |
| 街・前庭 | 花の鉢・旗が「道の上」と出る | 石畳の前庭に置く物で、入口・道はふさいでいない（決まりどおり） |
| 自分の家・案内の家・となりの家（古い部屋） | 壁ぎわ・机の奥に、歩けない床が1列ほど残る | 行けない出入口・物・人は無い（テストで確認）。小さな幅で、歩けるようにすると足が壁・家具に重なりやすいので今回はそのまま |
| バトル・場のカード | 見た目の高さが 24px | 見えない押せる所を 44px にしてある（前から）。絵の大きさは変えない |
| バトル・相手の正式な絵が出る | ユーザーの写真の場面を、自動の対戦では同じ形で出せなかった | 出る道（演出の途中でモンスターを押す）をふさいだ（表の 8）。iPhone でまだ出るか見てほしい |
| ダンジョン | 見える範囲が1マスのダンジョンは、写真が暗く全体は写らない | 遊ぶときの見え方のまま撮った。行けるかどうかはテストで全部の階を調べた |
