# 依頼文：カードショップの棚・ショーケースの商品

## いまの問題
ユーザーの指摘（写真 `09_shop_display_now.jpg` の赤い丸）：棚・ショーケースのカードが全部同じ無地の紺で、商品に見えない。

## 描く物（どちらか）
A. 今の家具の絵（`design-parts/cardshop-assets-20261027/assets/shop_furniture_*.png`）の、カード・パックの所だけを描き直した差し替え（同じ 1536×1024 のキャンバス・同じ位置・透過）
   - 対象：left_wall（左の壁の棚）・center_left・center_right（中央のガラスの展示台）・front_left（手前左の展示台）・right_wall（右の壁の棚）・right_display（小展示台）・back_left_shelf
B. 上に重ねる小さな部品のセット（透過 PNG）：
   - 立てて並べたパック（6色：ソラモ＝クリーム・ガウル＝橙・ラズック＝紫・ノビトン＝黄・ミュロル＝水色・カルシェル＝白っぽい青。ゲームのガチャのパックと同じ柄を小さく）横 40×高さ 70 px くらい、各色1枚
   - ショーケースの中に寝かせたカード（モンスターの絵柄が少し見える）横 48×高さ 64 px くらい、6種
   - ゲームが家具の上に並べる
- 塗り・明るさ：今の家具と同じ。ガラスの映りこみ・光の当たり方も同じ向き（左上から）

## ゲームに置く所
カードショップの部屋（`tools/design/cardshop_v2.py`）。A なら同じファイル名で置き換えるだけ。B ならゲーム側で家具の上に重ねる位置を決める。
