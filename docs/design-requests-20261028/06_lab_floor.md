# 依頼文：カード研究所の床（研究所らしく）

## いまの問題
ユーザーの指摘：「研究所の床をもっと研究所らしく」。いまは家と同じふつうの木の床（研究所の中の写真は報告書の「研究所」の写真）。

## 描く物
- 研究所の部屋の床だけの絵 1枚（家具・壁は描かない）。今の部屋の絵 `design-parts/rooms-20261028/Mistral_Room_lab_parts/lab_shell.png`（1536×1024）の床の所と同じ形・同じ大きさ
- 中身の案：板張りの床の上に、ところどころ石のタイル。タイルには魔法陣・星図（星と円の線）を金色の細い線で。中央の机の下と、右奥の機械の前に研究用の敷物（紺と金の模様）
- 色：今の木の床と家具（濃い木目・紺・金）に合う色。明るさは今の床と同じくらい。床が派手になりすぎて人が見えにくくならないように、模様はうすめ
- 見え方：今の部屋と同じ、少し上から見下ろす形（奥が少しせまい）
- 背景：床の外（壁の所）は透明でよい。または壁ごと描いた lab_shell の差し替え（1536×1024・不透明）でもよい
