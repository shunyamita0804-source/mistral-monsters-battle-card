# 依頼文：カード練習場の外観（正面向きに描き直す）

## いまの問題
ユーザーの指摘（写真 `12_practice_now.jpg`）：「建物が正面を向いていない」。いまの練習場は少し斜めで、左右で屋根の高さが違って見える。
扉が建物の真ん中から左にずれていて、扉の前の道とそろって見えない。
街の全体図での見え方：`12_practice_town.jpg`（西の道の北側）。

## 描く物
- カード練習場の外観 1枚。いまの絵（緑の屋根・カードの紋章の旗・木組みの壁）の特徴はそのまま、**正面向き・左右対称**に
- 大きさ：1536×1024 px（いまの `building_practice.png` と同じ横長）。建物は横 約 1300 px・高さ 約 800 px まで
- 扉：**正面の真ん中**の下の両開きの扉（扉の前の道が建物の真ん中から下へのびるので）。扉の高さ 約 260 px

## 今の街の絵との合わせ方（共通）
- 見え方：**正面向き（少し上から見下ろす）**。斜め45度にしない。壁の正面が画面に平行で、横の壁はほとんど見えない。屋根は上からのぞいて少し見える
- 2026-10-28 に正面向きに描き直した家7つ（花屋・仕立て屋・ピートの家・ハロルドの家・主人公の家・となりの家・大工の作業小屋）と同じ見え方にそろえる（見本 `12_front_ok_houses.jpg`）
- 塗り：今の街と同じ、くっきりした線のない厚塗りのドット絵風。明るさ・あざやかさは今の建物と同じくらい（1〜2割落ち着いた色）。光は左上から
- 石・木目の大きさ：扉の高さに対して、今の建物と同じ大きさの石・板
- 背景は**透過**（建物のまわりは透明）。地面の影は描かない（ゲームで付ける）
- 扉は1つ、真ん中の下。扉の下の段（敷居）の位置が分かるように、段は建物の正面の幅の中に収める

街の西（扉の位置は今のまま）。届いたら `design-parts/town-20261028/front-facing-20261028/building_practice.png` に置き、BUILDINGS の TRAINING の door を測り直す。
