# 2026-10-30 指示書 S：iPhone の試遊で見つかった街とカードショップの直し

絵の描き直しはしていない（置き方・切り方・重なりの順・当たりだけ）。街は `python3 -I tools/design/seimon_world_build.py design-parts/seimon-world 確認のフォルダ` で作り直した（約5分）。
作り直す前に、変えないまま作り直して今の絵と同じになることを確かめてから直した。作るには Python の scipy と matplotlib が要る（`pip install scipy matplotlib`）。

| # | 見つけたこと | 直したこと | 場所 |

| 1 | カードショップの「カウンター」の名札が店員ニーナの顔に重なる | 名札が家具の奥に立つ人の絵にかかるときは、人のとなり（人から遠い側）へずらす。管理局の「受付」（受付の人の体）・練習場の「練習テーブル」（先生）・大会会場の「受付カウンター」も同じ決まりで動く | `src/game/world/world.ts` の `labelCenterAwayFromPeople`・`worldScreen.ts` の `#addLabels` |
| 2 | 噴水の水が柱の途中（下の池の水）から出ている | 水柱の根元をいちばん上の受け皿の真ん中（金の飾りの足元）に合わせ、左右の筋が受け皿のふちに落ちる大きさ（0.9→0.62）に。しぶきは噴水の手前に重ね、受け皿の水の面・手前のふち・飾り・池の手前のふちの所は消す（飾りの先から出て、受け皿のふちの奥に落ちる） | `town2026_build.py` の `fountain_spray`・`FOUNTAIN_*` |
| 2′ | 受け皿から下の池へ落ちる水 | **未完了**：今のしぶきの絵では作れなかった（のばすと雨のすじ、くり返すと段に見える）。絵の依頼文を書いた | `docs/design-requests-20261030/10_fountain_overflow.md` |
| 3 | 高台の石垣が階段の左右でずれる・すき間に草・柱の間かくがばらばら | 石垣の絵はななめから見た絵（上のふち・下のふちが右下がり）だったので、列ごとにのばし縮めして上下のふちを水平に（`level_strip`）。階段で区切った区間ごとに、1枚＝左の柱＋塀で、柱の間かくをそろえて並べる（`wall_run`。長さに合う枚数にして少しだけのばし縮め）。階段のわきは石垣を階段の柱の下まで入れ、柱は2本並べない。区間の右はしに柱を1本 | `town2026_build.py` の `TERRACE_TOP`・`TERRACE_BOTTOM`・`face` |
