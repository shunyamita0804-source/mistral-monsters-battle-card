## 形

| ランク | 形 | 出場者 |
| --- | --- | --- |
| E | 4人の総当たり（1人3試合） | 主人公・ノエル・ヴィクトル・シエナ |
| D | 4人の総当たり | 主人公・ダリオ・イザベラ・ゴードン |
| C | 8人のトーナメント（3連勝で優勝） | 常連：シエナ・ドルフ・レナード ＋ C・B組から4人 |
| B | 8人のトーナメント | 常連：ドルフ・レナード・グレタ・ユリウス ＋ C・B組から3人 |
| A | 8人のトーナメント | 常連：レナード・グレタ・ユリウス・カミラ ＋ A・S組から3人 |
| S | 8人のトーナメント | 常連：ユリウス・カミラ・アルヴィン ＋ A・S組から4人 |

- 一般の出場者（名刺図鑑には載せない）：C・B組 トビアス・マリー・ジャン・ヘレナ／A・S組 クロード・ベアトリス・ザラ・ウォルター（顔は届いた絵）
- C ではシエナ、S ではアルヴィンを主人公と反対の山に置き、決勝まで必ず勝ち上がる
- 総当たりの順位：勝ち数 → 勝った試合で残った自分のモンスターの数 → 与えたダメージ → 抽選（同率1位は作らない）。1位なら優勝
- トーナメントで負けたら、その大会はそこで終わり（残りの試合は結果だけ出して表を埋める）。棄権も同じく表を埋める
- **ほかの人どうしの試合は、ふつうの対戦と同じルール・同じ思考の自動対戦で決める**（1試合 約1.5ミリ秒。確率では決めていない）
- C ランク大会を終えたら（優勝しても負けても）「シエナがいなくなった」の記録（`storyFlags` の `siennaLeft`）。ダンジョン・会話は作っていない

## 常連のデッキと考え方（すべて仮。`src/data/tournaments.ts` の REGULARS）

| 常連 | モンスター | デッキ | 考え方 | 勝率（表示・仮） |
| --- | --- | --- | --- | --- |
| シエナ | ソラモ・ミュロル・ガウル | 偏りのない構成 | ふつう | 64% |
| ドルフ | ガウル・ラズック・ノビトン | 必要マナの多い攻撃ばかり・守りなし | 攻撃を先に・守りは倒されそうなときだけ | 58% |
| レナード | ラズック・ソラモ・ガウル | 妨害の技2枚ずつ＋攻撃 | 手番の最初に妨害 | 66% |
| グレタ | カルシェル・ミュロル・ノビトン | 防御・回避が多い | いつも守る・守りを2枚残す・ドローで山札を減らさない | 72% |
| ユリウス | ガウル・ソラモ・カルシェル | 必要マナ4以上の大技が多い | 大技を先に | 80% |
| カミラ | カルシェル・ガウル・ミュロル | 強い攻撃と守りをバランスよく | 弱いモンスターを先に狙う | 91% |
| アルヴィン | ソラモ・ガウル・カルシェル | カミラと同じ組み方 | カミラと同じ・強さはいちばん上 | 100% |

- 強さ（ライフ倍率）：ランク C 1.15・B 1.25・A 1.35・S 1.5 に、人ごとの倍率（ユリウス 1.05・カミラ 1.1・アルヴィン 1.2・レナード 1.15・グレタ 0.85。ほかは 1）。一般の出場者は 0.95
- レナードとグレタは、ほかの人と自動対戦させて極端に弱い・強いにならないよう倍率を合わせた（レナード：妨害の考え方はいまのカードでは弱いので 1.15、グレタ：山札切れ待ちが強すぎたので 0.85）
- 常連の顔の絵（シエナ以外の6人）はまだ無いので人影

## 報酬（仮）

- E・D：いまのまま
- C〜S の初優勝：C 500G・B 600G・A 800G・S 1000G とランクアップ（C→B→A→S）。2回目以降は半分。参加賞 C 40G・B 50G・A 60G・S 80G。パック・カードの景品なし

## 画面

- 対戦表：届いた5×5マスの表の絵の上に、顔（枠つき）・名前・勝ち（金の輪）・負け（えんじの交差線）・自分どうし（斜線）・次の相手（光る枠）・自分の行（うすい帯）
- トーナメント表：左右4人ずつ、真ん中の上に優勝杯と台座。札（ふつう・勝ち残り・敗退）、2人をまとめる線（決まると勝った側が光る）、決勝の横線（決まると光る）、いま戦う所に剣の印。常連は札の上に二つ名。札を押すと顔・二つ名・名前・勝率・モンスター
- 2人をまとめる線は、飾りがゆがまないよう縦の棒の所だけを伸ばす（`tools/design/tournament_parts.py` で5つに分けて切り出し）
- 対戦の背景：C〜S は D と同じ

## セーブ（version 18）

- 途中の大会：組み合わせ・終わった試合（主人公の試合もほかの人の試合も）・seed。途中で閉じても次の試合から（試合の途中なら、その試合はやり直し）
- C〜S の初優勝の記録は今までの大会の記録と同じ所。`storyFlags` を足した
- 前の形式（v17）で大会の途中だったセーブは、その大会の1試合目からやり直し（参加の回数はそのまま）
