# 街と部屋の点検の直し（2026-10-29 夜）

進行チャットが街のデータを組み立てて見つけた所を直した（ユーザー指示）。作り直しは `python3 -I tools/design/seimon_world_build.py design-parts/seimon-world`（約5分）と `python3 -I tools/design/rooms4_build.py`。

## 直したこと

1. 入口の名前：住宅A（HOUSE_A）は「花屋」、住宅D（HOUSE_D）は「仕立て屋」（`maps.ts` の TOWN_DOORS。英語 Florist・Tailor）。中の部屋は今のまま「民家」の絵。
   - 街の画面では、入口の名前は出ない（建物の上の名前の札は、大会会場・研究所などの施設だけ＝`TOWN_SIGNS`）。花屋・仕立て屋の札を出すかは返事待ち
2. 管理局の中：左手前の掲示板を、入口の左の柱の上（左の長いすの右・カウンターの手前）へ動かした（`rooms4_build.py` の `moves`）。
   そのままの大きさでは床の中に家具に重ならずに入る所が無いので 0.7 倍。掲示板の絵に入っていた長いすの背・床のふち・植木の葉の切れはしは持っていかない（`keep`）。
   当たり（掲示板の足もと）と「調べる」の場所も合わせた
3. 街：北の高台の東のふち（大工の小屋の左。x 4300・y 300〜1560）の縦の細い石の帯（白い線に見えた）を、絵と当たりの両方から消した。
   柵・植え込みにはしていない。高台の草の明るさの境目は線にならないようにぼかした
4. 街：石の橋と小川（下の「橋の直し方の案」）
5. 街：東の大通りのはし。花屋の右〜東の道・商店街のはし（y 2250〜4100）では、林の手前の列の木と植え込みを置かず、奥の列も林の奥へ下げた（`EAST_CLEAR`）。
   大通りの東のはしは、植え込み2つ・街灯1本・花壇1つ（はしの林の手前。花壇の数を減らした）
6. 街：南東の公園のベンチ（3780, 5920）が手前の木に半分隠れていたので、木2本を東へ（3950 → 4260・4550 → 4720）。ベンチも少し西へ（3850 → 3780）

## 橋の直し方の案

- **案A（こちらにした）**：小川の曲がり方を変える。橋の西（x 2450）で南へ曲げて橋の床の下（y 5015）を通し、橋の東（x 3800）でもう一度南へ曲げて前の流れ（y 5500）へ。
  橋は動かさない。南の大通り・南の門のまわりの物も動かさない。橋の東の曲がり角に合わせて、いちばん西のベンチを少し東へ（4000 → 4100）
- 案B（やめた）：橋を小川の上まで南へ下げる（約 485 単位）。橋の下の端が南の門の近くまで来て、南の大通りの街灯・ベンチ・花鉢・マンホールと重なる。道の形も変わる
