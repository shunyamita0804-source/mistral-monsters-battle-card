- **ウズリオの薄い茶色**：最初の候補（#C9A089・#B98A70・#D9B49C）は、枠を作る道具が明るい色を薄くするので、どれもギアロスの桃色・ガウル・ソラモと見分けにくかった。
  次の候補のうち **#A87A5E を「濃いめのしかた」**（場の枠：`battle_card_frame.py` の `FORCE_DARK`〔ハクランと同じ〕・技カードの帯：`skillcard_simple_build.py` の `LIGHT_MIX` 0.3〔フォルンと同じ〕）で作ったものが、
  ソラモ（クリーム）・ジオル・ギアロス（桃色）・ガウル（オレンジ）・ノウス（茶色）と見分けやすかったので選んだ（写真 `uzurio_candidates_*`）
- ヒョウズクの氷の青は、セレフィーン（青紫）・ミュロル（水色）と見分けられる（前のウズリオの色と同じ）
- 直した所：
