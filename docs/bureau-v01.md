## 実装済み

- 中の部屋：`tools/design/bureau_v01.py` が床と壁（ROOM_SHELL）・奥の書類棚・受付カウンターを同じ原点のまま並べる
  （家具だけの切り抜きでも位置は変えない）。書き出し `assets/images/maps/rooms/bureau_*.webp`・`src/data/bureauArt.generated.ts`
- 大きさはカードショップと同じ（絵の 1px ＝ 1.25 単位、部屋 1920×1280 単位、人の背は絵の中で約178px）
- 歩ける所は LAYOUT_SPEC の多角形。カウンター（足元 x470〜1066・y445〜555）は通れない。カウンターの奥の受付の人の所も通れない
- 重なり順：棚（足元 y283）→ 受付の人 → カウンター（足元 y553）→ 主人公。受付の人は腰から下がカウンターに隠れる
  （LAYOUT_SPEC の足元 y425 だとゲームの人の大きさでは膝から下しか隠れないので、y448 にした）
- 入口は扉のない開いた通り道（v01 の提案どおり）。入ったときは通り道の上（上向き）。出口を踏むと街の入口の前へ
- 受付の人に話す・カウンターを調べる → いまある仮の1行（地の文）。導入イベントでは前からある場面（受付の台詞・パック選び）をそのまま使う
- 導入イベントで主人公が止まる所＝受付の前（`BUREAU_DESK_FRONT`。受付の人から2マス）。幼馴染は前の仕様どおり外で待つ（部屋の中では重ならない）

## 暫定

- 受付の人の絵（歩く絵・顔の絵）は大会会場の受付の流用。大会会場の受付は置き換えていない。
  差し替えは `worldScreen.ts` の `NPC_SHEET.bureau_clerk` と `dialogue.ts` の `PORTRAITS.bureau_clerk` の2か所
- 受付はエレノア（No.06。2026-10-27）。英語名「Card Battler Bureau」は仮訳

## 街の上の場所（2026-10-27 ユーザー決定）

- **北東の、もとの住宅C の所**（ユーザー指示「管理局は赤枠のとこにおこう」→ 住宅C は「管理局に置き換える」）。
  住宅C・その部屋（house-c）・住人C（大工）と会話はなくした。住宅C の中にいたセーブは、読み込むと自分の家に戻る
- 枠・玄関・道は住宅C と同じ（設計図 `seimon_town_pack.py` の BUREAU：rect [2912,288,3488,768]、玄関の中心 x=3200、道 P_BUREAU）。
  枠を広げると草むら・小物の並びが街じゅうずれるため、同じ枠にした。作り直した街の絵で変わったのは `town_r0c2.webp` の住宅C の所だけ（ほかの8枚・部屋の絵は1画素も変わらない）
- 外観は `seimon_world_build.py` が `bureau_v01.town_exterior()` を焼き込む（ほかの建物と同じ陰・縦1.1倍）。施設の名前の札「カードバトラー管理局」（英語は仮訳）
- 玄関のマスは (98〜101, 23)、出たときに立つ所は (100, 24)。扉は閉じた絵のまま（踏むと暗転して中へ。ほかの家と同じ）
- 前に置いていた【仮】の印（中央の通りの西の端）は消した
