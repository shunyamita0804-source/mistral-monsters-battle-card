## 1. 受付カウンター「左の端に主人公が重なり、そこから動けなくなる」

- 原因1：セリアのまわり（よこ2マス・たて1マス）が、受付の前の行（29行）の 47〜51列をふさいでいた。
  前の行を右へ歩くと、カウンターの左寄り（46列）で見えない壁に止まり、主人公の体がカウンターの左の方に重なって見えた（前の P0-6「受付の前で止まる」と同じ所）
- 原因2：主人公の絵は約3マスの幅なので、カウンターの左右のはしの横の列（42列・56列）に立つと、体がカウンターのはしに重なった
- 直したこと
  - セリアのまわりは本人のマスだけ（`maps.ts` の `spotNpc` に `forceBehindCounter`。研究所・管理局などカウンターの奥の人と同じ）。前の行を歩いて、セリアの真ん前まで行って話せる
  - カウンターの左右のはしの横の1列（42列・56列の 24〜28行）をふさいだ（`rooms4_build.py`）。カウンターの前の行（29行）はそのまま
- 気になる所：セリアの真ん前に立つと、主人公の帽子がセリアの足もとにかかる（カウンターの手前に立って見える）

## 2. 入口「柱と低い壁の手前で引っかかって外へ出られない」

- 原因：柱のすぐ外の 30行（20列・39列）は、柱の頭と低い壁の石が3分の1ほどかかるマスで、入ると下（低い壁）にも柱の方にも進めない行き止まりだった
  （スティックは上下左右の4方向だけなので、下へ倒したまま入ると抜けにくい）
- 直したこと：その2マスをふさいだ（`rooms4_build.py`）。柱のあいだの通り道は柱の絵のふちからふちまでの 12マス（24〜35列）で、見た目と同じ（変えていない）
- 透明なのに当たりのあるマス：入口のまわりには無い（点検の道具で確かめた）
