# 作業報告書（2026-10-28 深夜：手札の大きさ・数字・手札の印・枠のくっきり化）

保管してあった「手札の大きさ」の指示書と、同じ日にいただいたご指示（手札の印・枠を2倍の大きさに）をまとめて行いました。
すべて公開済みで、公開ページでも確かめました。iPhone の実機ではまだ確かめていません
（パソコンのブラウザで 390×844 と 375×667 を、iPhone と同じ3倍の細かさで確認）。

## 2. 指示書とちがう所・Claude が決めたこと（気になれば教えてください）

- **「縦が足りない画面（375×667 など）だけ幅 80 に戻す」決まりは作りませんでした**。
  この遊びの画面は、どの iPhone でも縦 844 の大きさで組んでから、画面に合わせて縮めて表示する作りです。
  375×667（iPhone SE）では横が少し広くなるだけで、縦の余裕は 390×844 と同じです。
  幅 90 のままで手札・場・ボタンが重ならず切れないことを、両方の画面の写真で確かめました
- 相手の手札（裏面）は「今どおり」なので、大きさは変えていません（多いときは今までどおり重ねる）
- 光の色：マナにする＝マナの玉と同じ水色、選んだ＝金色。使えないカードを選んだときは、灰色のまま金色に光る
- 確認用のボタン（`?qa=1` のときだけ）に「QA:手札+1」を足しました（手札が7枚・10枚の写真を撮るため）。ふだんの画面には出ません
