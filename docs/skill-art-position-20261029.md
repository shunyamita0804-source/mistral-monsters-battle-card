# 技の絵の左右の位置（2026-10-29）

ユーザー指示：大きなカードで絵が切れる技を、絵の左右の位置をずらして直す（描き直しはしない）。

## 1. したこと

- 技ごとに絵の横の位置（CSS の object-position の x）を決められるようにした：`src/data/skillArtPosition.ts` の `SKILL_ART_X`（決めていない技は 50%＝真ん中）
- 使う所：技カードの絵（`skillCard.ts` の `artLayer`。大きなカード・手札・図鑑・デッキ編集・ガチャのめくる所・取得カードなど、技カードの絵はすべてここ）と、
  ガチャの機械の上のラインナップの小さな枠（`gachaMachine.ts` の `lineupArt`）

  | 技 | 位置 |
  | --- | --- |
  | ソラモ 04 しっぽアタック | 100% |
  | カルシェル 02 シェルタックル | 75% |
  | カルシェル 13 てっぺきシェル | 40% |

- てっぺきシェルの 40% は、左の貝のとがった先が少し多く見える代わりに、右の顔は少しだけ右のはしへ寄る（指示の値のまま）
