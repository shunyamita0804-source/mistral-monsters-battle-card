## 2. 新しい効果（裁定は `docs/battle-rules.md`「プカリム（試遊中）」）

- 09 ほっぺにためる：プカリムの次の攻撃技＋2。使うまで続く・重ねない・攻撃技を使ったら（当たっても・守られても・回避されても）消える・倒れたら消える。
  場のプカリムに「ためている」の印（ふくらんだほっぺの丸い印。仮の見た目。相手からも見える）
- 07 ぷはーっ：ためているときは回避されない（3＋2＝5。防御の軽減はふつうに受ける）。ためていなければふつうの3
- 10 おいかぜ：プカリム以外の味方1体の、**次の自分のターンだけ**攻撃技＋1（2026-10-29 にカードの文のとおりに直した。かけた同じ手番には効かない）。
  次の自分のターンに攻撃技を1回使うか、そのターンが終わったら消える。味方に「おいかぜ＋1」の印（＋1 が効くターンまで出す）
- 相手の CPU：その手番に倒せないときは、ほっぺにためる → 次の手番にためた攻撃（ぷはーっは少し優先）。ほっぺにためるが無ければおいかぜ
- テスト：`tests/pukarim.test.ts`（重ねられない・使ったら消える・守られても回避されても消える・倒れたら消える・回避されない・防御はできる・おいかぜは1回・期限・CPU の流れ）

## 4. 気づいたこと（数字は変えていない。直し方は進行チャットで）

- 強すぎ：60% を超えた組み合わせは無い。ただ、ノビトンの代わりに入れると勝率が大きく上がる（烈火 55.2%・蒼海 59.0%）。
  プカリムが強いというより、入れ替えた側（ノビトン）とのくらべの差と思われる
- 目安（6体の中で少し弱め＝40〜50%）より少し高め（平均 51.6%）
- ほっぺにためる：ためたあとの攻撃の平均は 3.4 と控えめ。CPU は、ためたあと手札で一番強い攻撃を使うが、手札に大技が少ない（おおつむじ1枚・ボディプレス1枚）ので、
  多くは「しっぽ・たいあたり・ころがる＋2」になっている。おおつむじでの一撃は 5,400 回中 71 回と少ない
- ためた 30% は使われずに終わる（プカリムのライフ6が低めで、先に倒されやすい）
- おいかぜは CPU があまり使わない（ほっぺにためるを先に使う思考のため）。おいかぜ単体の強さは、この試遊ではほとんど測れていない
- 試遊の数字は「試遊用の16枚（Claude の仮）」と CPU の思考（仮）に左右される

## 7. 2026-10-29 の直し（その2）

- 相手の CPU がおいかぜを使う条件を「次の自分のターンに攻撃できそうな味方がいるとき」にした（`ai.ts` の `chooseChargeOrTailwind`）。
