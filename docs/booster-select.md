## 選び方（`src/game/story/boosterSelect.ts`・画面は `worldScreen.ts` の `#choosePack`）

- 3箱を横に並べる。初めは「気になる箱をタップしてください。」
- 1回目のタップ：その箱が少し浮いて光り、上に指が出る。下の枠にミレイユの顔とひと言（依頼の台詞のまま）＋「同じ箱をもう一度タップすると決定します。」
- 同じ箱をもう一度タップすると決定（確かめる窓は出さない）。別の箱をタップしたら、その箱の1回目に切り替わるだけ
- 連打で決まらない：1回目から 0.45 秒のあいだの同じ箱のタップは数えない。決まったあとはどの箱も押せない
- 受け取りは ID で1回だけ（前からの `claimBooster`）。決まったら受付のお礼 → 外へ（前と同じ流れ）
- ミレイユは管理局の中にも立つ（案内してから受け取るまで。`guide-bureau`）
