## 【1】仕掛け：赤と青の切り替えの扉

- 階には **赤の扉**（マスの文字 `R`）と **青の扉**（`B`）。開いているのはどちらか一方の色だけ。階に入ったときは赤が開いている
- スイッチを調べる（「調べる」ボタン・Z キー）たびに、開いている色が入れかわる。何度でも押せる（`run.ts` の `pressSwitch`）
- 階の作り方（`src/game/dungeon/generate.ts`）
  - 扉は通路のマスだけ（部屋のマスは扉にしない）。「いちばん少ないマスで2つの場所を分ける所」（`minVertexCut`）を扉にする
  - 1・2階：スタートとゴールの部屋のあいだを青の扉で区切る＋飾りの赤の扉1つ。スイッチ1つ（スタートの側）。1回切り替えるとゴールへ
  - 3〜5階：スタート ─青の扉─ 途中の部屋 ─赤の扉─ ゴール。スイッチ2〜3つ（1つ目はスタートの側・2つ目は青の扉の向こう・3つ目はどこか）。扉4〜6か所（足りなければ飾りの扉を足す）
  - 「いる場所 × 開いている色」で全部調べて（`switchPuzzle`）、決まりに合う階だけを残す：どの状態からでもゴール（階段・ボス）へ行ける／全部のバトラー・宝箱・スイッチのとなりへどれかの状態で行ける／扉のマスにだれもいない／スイッチは扉のとなりに置かない（扉の上に立ったまま切り替えないように）
  - 同じシード・同じ階なら必ず同じ階（中断して再開しても同じ）。ほかのダンジョンの階は変わらない
- 見た目
  - 扉：今の `machine_door_closed／open` を赤と青に染めた絵（形は同じ。`tools/art/machine_door_colors.py`）。開いた扉の足もとはその色のうすい光（床と見分けがつくように）
  - スイッチ：赤が開いている＝赤のレバー（今の `machine_switch_off` を赤に）／青が開いている＝青のレバー（`machine_switch_on` を青に）
  - 上の帯の左（場所の札の左）：いま開いている色の丸い印（文字なし。読み上げは「赤の扉が開いている」など）
  - ミニマップ：扉は色つき（閉じている＝こい色・開いている＝うすい色）。スイッチは金色の四角に開いている色のふち
  - スイッチを押したとき：短い音（宝箱を開ける音と同じ）・扉とスイッチが少しゆれる動き（0.42 秒）・お知らせ「青の扉が開き、赤の扉が閉まった。」など
- セーブ：**version 36**。`dungeonRun.switchFloor`（扉を開けた階）をやめて `blueDoorFloor`（青が開いている階。ほかの階は赤）にした。
  理由：開いている色を中断から再開しても同じにするため。機械の塔の階の形が変わったので、前のセーブで機械の塔の挑戦の途中なら、いまの階のスタートからやり直す（見た地図は消す。倒した相手・開けた宝箱・手に入れたカードはそのまま）
- CPU の自動歩行：ダンジョンには案内の自動歩行が無い（街の自動歩行だけ）ので、直すところは無かった

## 要確認

1. 指示書は「スイッチを**踏む**」だが、今までどおり「スイッチの方を向いて調べる」で切り替える（場面の文は指示書のまま「踏む」）。踏んで切り替える形にするか
2. 1・2階の飾りの赤の扉（赤が開いていることが分かるように1つ置いた）。要らなければ外す
3. floorLife の 0.95（2階）は 0.97 と同じ強さになった（ライフの端数が丸まるため）。2階だけ前より少し強め（勝つ割合 81 → 77％）
4. スイッチを押したときの音は宝箱を開ける音と同じ。専用の音があれば差しかえる
5. 上り階段の絵（今は下り階段の絵のまま）・説明の絵（赤と青の扉とスイッチ）があるとよい
6. 上の帯の色の印は、今の扉の絵（開いた扉）を色の丸に重ねた仮の印。正式な印の絵があれば差しかえる
7. 対戦で場のカードを大きく見たときに居場所の印を足した（前は無かった。古い印ではない）。要らなければ外す
8. 前のセーブで機械の塔の途中だった人は、いまの階のスタートからやり直しになる
