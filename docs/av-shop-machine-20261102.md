## 要確認

1. 機械を小さくしたので、機械のわき（左はカウンターとのあいだ・右は棚とのあいだ）に床が少し見えるが、前と同じく入れない（機械の置き場。入ると主人公が機械に重なる・行き止まりの細い通り道になる）
2. 「新入荷」のパックの絵は小さい（板の内がわ。390 の画面で約17×24px）。主人公が機械の前に立つと札が体に隠れる
3. 並んだ順は「店に入ったとき・パックを買ったとき」に記録する。店に入らないあいだに2つ以上並んだら、GACHA_SERIES の並びの順に足す
4. 主人公の背の「約1.5倍」の目安より少し大きい（約1.7倍）。指示の「約7割」を優先した
