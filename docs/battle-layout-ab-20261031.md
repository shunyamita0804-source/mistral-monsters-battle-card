## 変えたこと

1. **説明の欄**：横いっぱいの大きな箱をやめ、PS版のように「左に小さな説明の箱・右に大きなカード」。高さ 264 → **200**（`DETAIL_MAX_H`）。
   - 大きなカード：手札を押したとき・技を使ったとき・守りの選択。何も選んでいないときは、直前に使われたカードを薄く（まだ無ければ空の点線の枠）
   - 案内の文を1〜2行に短く（「手札をタップで説明。上へはじくとすぐ使えます」）
2. **モンスター**：`MONSTER_ICON` 76 → **88**（約1.16倍）。情報の箱は今の位置のまま
3. **自分の手札**：`HAND_CARD_W` 90 → **98**
4. **相手の手札**：自分の手札と同じ大きさ（98×123）の裏向きで、枚数ぶん（前は 82 幅もとの高さ 103）。裏面の絵は上下を少し縮めて合わせた
5. **カメラ**：上の帯と操作のボタンのあいだを1本の帯（上から 相手の大きなカードの欄・相手の手札・相手3体・自分3体・説明の欄・自分の手札）にして、0.3 秒でずらす
   - 相手が動く・相手のカードを見せている間：相手の側（相手が使ったカードを左に大きく・説明を右、その下に相手の手札・両方の3体。自分の手札は画面の下の外）
   - 自分の番・自分のカードを見せている間・守りの選択：自分の側（相手の手札は下のはし 56px だけ見える）
   - 守りの選択では、手札の場所も守りの選択の欄に使う（前と同じ。守りのカードの絵を 60 → 76 に）
   - 欄の高さ・ずらす量は画面の高さから決める（`battleScreen.ts` の `layoutCamera`）。説明の欄が 200 より大きくなる分は、相手3体と自分3体のあいだを空ける
6. 390×844 の論理画面。375×667 でも同じ配置を縮めて出す（ボタン・手札・ライフは切れない。写真で確認）
