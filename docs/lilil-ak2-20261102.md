## 2. CPU のうっとりウインク・うそなき（ユーザー決定）

`src/game/battle/ai.ts` の `chooseLililTrick`。決まりは `docs/battle-rules.md`「CPU のうっとりウインク・うそなき」。
**リリルだけ**に当てた（ラズックのおびきよせ・カルシェルのすなをほるは前の考え方のまま。ほかの箱の強さを変えないため）。

- うっとりウインク：手札にリリルの回避があり、次の相手の手番に払えるときだけ使う
  - 相手の攻撃が強い（リリル以外の味方が、相手がいまのマナで払える攻撃で倒されそう・または相手のマナが4以上）→ 攻撃より先に
  - そうでなければ攻撃のあとに。狙いはいちばん攻撃の強い相手
- ウインクを使ったら、リリルの回避はマナにしないで残す（腕前 C でも）
- **ウインクの効いている手番にリリルが狙われたら、1〜2 ダメージでも回避する**（ふだんの CPU は 3 以上か倒されそうなときだけ回避する。そのままだとウインクのあとの小さな攻撃を回避しないので、Claude が足した。要確認1）
- うそなき：リリルのライフが半分以下で、相手の攻撃で倒されそうなとき（その手番に倒せる攻撃が無ければ攻撃より先に）
- 腕前 C は 30% の手番でこの2枚を使いそこねる（`CPU_SKILL.forgetTrick`。前からある「捨て身の技を忘れる」と同じ 0.3）
