# ダンジョンの壁と床の見分け（2026-11-05 ユーザー指示）

ブランチ `dungeon-wall-contrast`（**main には入れていない**・確認待ち・**公開はしない**）。絵は描き直さず、コードだけで。全部のダンジョンに同じしくみで効く。

## 試したこと・選んだ組み合わせ

| 方法 | 結果 |
| --- | --- |
| 壁の上面を床より暗く・色をうすく（明かりの外は明るさ 55％、明かりの中は 70％） | **採用**。いちばん効いた。部屋と通路の形がはっきりする |
| 壁の手前の面を見せる | もともと出ている（下が床の壁）。暗くしないで残し、壁の高さが分かるように |
| 壁から床へ短い影（上の壁は少し長め・左右の壁は短め） | **採用**。床のふちが締まって、壁が立って見える |
| 壁と床の境目に細い線（床に面した壁のふちに、細い明るい線） | **採用**（うすめ）。壁の上面のかたまりのふちが分かる |
| 明かりの外の床を少し明るく（125％） | **採用**。前に見た所でも床と壁の差が出る |

- しくみ：`dungeonRunScreen.ts` の `wallEdge`（となりのマスが壁かを見て、影・線を `--edge` に入れる）・`dungeonRun.css` の最後。影と線は見たマスだけ（まだ見ていない壁の形は分からないまま）
- 写真の道具 `tools/e2e/dungeon_wall_shot.cjs`（12のダンジョン・390×844・直す前／後）。イベントのダンジョン3つはまだダンジョンとして入れないので、太古の遺跡の1階の形にその見た目を付けかえて撮った

## コードだけでは足りないダンジョン

- **静かなる祭壇**：壁の上面の絵が床とほとんど同じ石の格子なので、暗くしても床に見えやすい。壁の上面の絵の描き直しがよい
- ほかの11（風の渓谷・水の神殿・精霊の森・氷の洞窟・炎の火山・太古の遺跡・雷の高原・機械の塔・天の聖域・霧の廃坑・忘れられた書庫）はコードで見分けられるようになった
