## したこと

1. 絵
   - 技の絵14枚：原本 `art/skills/pukarim_sk_NN.png` を `tools/art/card_art_webp.py` で `assets/images/cards/skills/puk_sk_NN.webp`（幅 827）に。番号＝技番号
   - 正式モンスターカード：`pukarim_official.webp`（幅 508 に縮めただけ。ソラモ・ガウル・ノビトンと同じ使い方＝図鑑・ショップなどのカード）
   - バトル用の絵は今のまま。技・モンスターの「絵が未定」「レアリティ未定」の印は外した
   - ガチャのレアの枠：7 ぷはーっ・14 ぷかぷか（`economy.ts` の `GACHA_SERIES`）
2. ふつうに遊ぶ人に出す：`cards.ts` の `MONSTERS`・`SKILLS` へ移した（図鑑の番号 No.091〜105）。初期配布・ブースターの箱には入れない。
   確認用の「プカリムの試遊」（?qa=1）は残した。図鑑の研究員の文に「プカリム」を足した
3. ピートとの勝負（`src/game/story/pete.ts`・会話 `storyScenes.ts` の pete*・台詞 `story.pete.*`）
   - 管理局で箱を受け取ったあと（前の形式のセーブ・導入を飛ばしたセーブも）に話しかけると「勝負する／やめておく」
   - 箱を受け取る前は、導入のイベント中で自由に歩けないので、ピートには話しかけられない（今の台詞のまま）
   - ピートのデッキ：プカリム・ソラモ・ノビトン（lifeScale 0.6）。背景は草原。負けても何も失わない
   - 初めて勝ったら：プカリムのモンスターカード1枚 →「取得カード」の画面で見せる。そのあとガチャにプカリムのシリーズが並ぶ
   - 2回目からの勝ち：プカリムの技からランダムに1枚（ダンジョンの勝ちと同じ決め方。お金なし）
   - セーブ：初回の報酬を受け取った記録は `storyFlags` の `pete-beaten`（形式は変えていない。前のセーブは「まだ」）。同じ勝ちは ID で1回だけ
   - 名刺図鑑：ピートとの対戦も記録される（`people.ts` の opponentIds）
4. 相手のチーム：太古の遺跡・精霊の森のバトラーと見えない番人、大会 E（ノエル・ヴィクトル・シエナ）、大会 D（ダリオ・イザベラ・ゴードン）、
   C のゴードンを指示書どおりに入れ替えた（強さは今のまま）。相手のデッキの技は今の作り方で自動でプカリムの技が入る
