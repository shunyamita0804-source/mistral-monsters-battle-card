# 指示書 V：デッキ・ガチャ・ボスのデッキ・宝箱の重なり（2026-10-30）

数字（勝つ割合・lifeScale）はすべて仮。測り方は「最初の手持ち（3つの箱）× 相手」を CPU どうしで対戦。先攻・後攻は半分ずつ。

## 1. 同じモンスターは1つのデッキに1体まで（V1）

- `DECK_RULES.allowDuplicateMonsters: false`（正式。`docs/battle-rules.md` の1番）。`validateDeck` は「同じモンスターは1体までです」を問題に入れる
- デッキ編集（モンスターを選ぶ）：ほかの枠にいるモンスターは一覧で薄くなり「デッキにいる」の札。押すと「〇〇はもうデッキにいます（同じモンスターは1体まで）」が出て「この枠に入れる」は押せない（日本語・英語）
- 前のセーブ：デッキ・カードは書きかえない（同じモンスターのカードも消さない）。**セーブの version は上げていない**（形式は変わらないため）。
  対戦（練習・ダンジョンのバトラー）・ダンジョンへ出発・大会の受付・メニューで「同じモンスターは1つのデッキに1体までになりました。家の机でデッキを組み直してください。」
- 相手の編成を3体ともちがうモンスターに（テスト：どの相手も3体ちがう）

| 相手 | 前 | 今 |
| --- | --- | --- |
| 仮の編成 TEST_TEAM（練習の相手など） | ソラモ・ラズック・ソラモ | ソラモ・ラズック・プカリム |
| 仮の編成 TEST_TEAM_ALT | ラズック・ソラモ・ラズック | ラズック・ソラモ・プカリム |
| 太古の遺跡・氷の洞窟の見えない番人 | カルシェル・ノビトン・カルシェル | カルシェル・ノビトン・ミュロル |
| 水の神殿の見えない番人 | カルシェル・ミュロル・カルシェル | カルシェル・ミュロル・ノビトン |
| 火山の見えない番人 | ガウル・ガウル・ラズック | ガウル・ラズック・ノビトン |
| 機械の塔の見えない番人 | ラズック・ノビトン・ラズック | ラズック・ノビトン・ガウル |

- 3体目をプカリムにした理由：ガウル・ミュロル・ノビトン・カルシェルは「前の初期デッキ・練習の相手に入れない」決まりがテストにある。
  プカリムのカードは createNewSave（テストや前の形式の土台）の手持ちに入るが、「最初から」の本当のセーブ（createNewGameSave）はカードを持たないので、遊ぶ人には関係しない
- 前の編成（ソラモ・ラズック・ソラモ）は、前のセーブのデッキを見分けるためだけに `LEGACY_TEST_TEAM` に残した
- 強さ（最後の階、200回×3箱。`docs/design/boss-ace-20261030/guardians_*.json`）：どのモンスターに替えても前と同じ強さにはならなかったので、ライフで近づけた

| 相手 | 前 | 組みかえただけ | ライフを合わせたあと |
| --- | --- | --- | --- |
| 遺跡・氷の番人（1.2） | 36.8％ | 22.3％ | **31.8％**（guardianLifeBonus −0.2。±3 に入る値はなく、いちばん近い） |
| 水の神殿の番人（1.1） | 26.2％ | 24.2％ | そのまま |
| 火山の番人（1.4） | 24.7％ | 18.5％ | **26.0％**（−0.2） |
| 機械の塔の番人（1.5） | 22.8％ | 17.3％ | **23.2％**（−0.3） |
| 練習の相手（0.6） | 64.0％ | 91.7％ | **71.3％**（lifeScale 0.65。±3 に入る値はなく、いちばん近い） |

- 古い固定の地下（`enc-b1-a` など。今のダンジョンでは使わない）は lifeScale を変えていない

## 2. ガチャのモンスターカードは「まだ持っていないとき」だけ（V2）

- `drawSeriesPack(series, seed, ownsMonster)`：そのモンスターのカードを1枚も持っていないときだけ 5％ でモンスターカード（天井なし）。持っていれば、モンスターの抽選をせず技14種だけ
- モンスターの種類は問わない（これから増える「大会で開くガチャ限定のモンスター」も同じ決まりで動く）
- 中身の15枠はそのまま（持っているものは絵、持っていないものは ?）
- 提供割合：「モンスターカード：まだ持っていないときだけ、1パックに5％」／"Monster card: 5% per pack, only while you don't have it yet"
- `src/data/economy.ts` の GACHA の説明も直した

## 3. ボスのデッキ：切り札の技を2枚ずつ（V3）

- ボス8人に切り札（`ace`）＝真ん中のモンスター＝祭壇でもらえるモンスター。グラント＝ジオル、セラ＝フルーネ、ルシア＝セレフィーン、ゼフィラ＝ツムジ、
  イヴァン＝カルシェル、バルカ＝ガウル、テオ＝ラズック、アウレリオ＝ソラモ（後ろの4人は仮）
- デッキ（`buildAceDeck`。60枚）：サポート → 切り札の技14種を2枚ずつ（28枚）→ ほかの2体の技を順に → 足りなければサポート。並び（真ん中が切り札）はそのまま
- 切り札の無い相手（大会・バトラーなど）は前の作り方のまま
- lifeScale は、直す前の勝つ割合から ±3 ポイントに入るように合わせた。200回だと1回ごとのぶれ（±2〜3 ポイント）が大きいので、**1000回で決め**、200回でも確かめた
  （`npm run playtest:bosses`・`tests/bossPlaytest.test.ts`。PLAYTEST_SCALES で lifeScale を変えて測る、PLAYTEST_NO_ACE=1 で直す前のデッキ）

| ボス | lifeScale 前 → 今 | 200回 直す前 → 直したあと | 1000回 直す前 → 直したあと |
| --- | --- | --- | --- |
| グラント（遺跡） | 1.2 → **1.05** | 15.8 → 16.0（+0.2） | 17.6 → 14.7（−2.9） |
| セラ（森） | 0.75 → **0.7** | 54.3 → 56.7（+2.3） | 53.1 → 53.9（+0.8） |
| ルシア（水） | 1.2 → **1.2** | 23.2 → 18.7（−4.5） | 20.4 → 19.2（−1.2） |
| ゼフィラ（風） | 1.0 → **1.1** | 22.0 → 19.8（−2.2） | 21.6 → 19.8（−1.8） |
| イヴァン（氷） | 1.3 → **1.6** | 19.5 → 23.8（+4.3） | 21.2 → 26.9（**+5.7**） |
| バルカ（火） | 1.5 → **1.75** | 19.7 → 24.7（+5.0） | 18.1 → 24.7（**+6.6**） |
| テオ（機械） | 1.6 → **1.2** | 24.2 → 27.8（+3.7） | 25.5 → 25.3（−0.2） |
| アウレリオ（聖域） | 1.75 → **1.75** | 12.8 → 14.7（+1.8） | 14.3 → 13.3（−1.0） |

- **イヴァン・バルカは ±3 に入らなかった（未完了）**。ライフを上げても勝つ割合が 25〜27％ より下がらない（最初の手持ちは、ボスの山札が切れて勝つことが多く、
  ライフを増やすと長引いて山札切れが早く来る）。いちばん近い値にした。合わせるには、ボスの編成・ほかの2体を変えるなど別の手が要る
- ゼフィラ（ツムジ）：Wひっかきを2回続けて使った回数 0 → **12**（200回×3箱）／58（1000回×3箱）、かぜのり 65 → **279**（200回×3箱）／369 → 1473（1000回×3箱）
- 前の試遊（`tests/flunePlaytest.test.ts`・`zephyraPlaytest.test.ts` など）は、その時のデッキ（切り札なし）の記録として残している

データ：`docs/design/boss-ace-20261030/`（before_200・before_1000・after_200・after_1000・scan_after_200・scan_after_1000・guardians_*）

## 4. ダンジョンの重なり（V4）

- 人・宝箱・飾り・階段・扉を**行の順**（画面の上から下）に重ねる：`z-index = 100 + 行×2`（人・動くものは +1。同じ行では人が前）。どのダンジョンも同じ
- 床に描く飾り（ひび・羽根・敷物・紋章・霧・落ち葉・橋・レール・石板）は今までどおり下
- 宝箱が人の1つ上の行にあると、人の頭の上に箱がかぶっていた → 人が前になる（`src/ui/screens/dungeonRunScreen.ts` の `rowZ`）
