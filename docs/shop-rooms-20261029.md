# 花屋・仕立て屋の中を新しい部屋に（2026-10-29）

ユーザー指示（チャット）。ZIP「Mistral_Room_florist_parts」「Mistral_Room_tailor_parts」（進行チャットでユーザー承認済み）。

- 原本：`design-parts/rooms-20261029/Mistral_Room_florist_parts/`・`Mistral_Room_tailor_parts/`（無改変）
- 作り方：部屋4つと同じ（`tools/design/rooms4_build.py` の `build_room` を使う別の道具 `tools/design/rooms_shop_build.py`）。
  書き出しは `assets/images/maps/rooms/room_florist_*.webp`・`room_tailor_*.webp` と `src/data/shopRoomsArt.generated.ts`
  - 1536×1024 の部品を左上でそろえて重ねる。家具は足もとの y で人と前後。front（手前の低い壁と入口の柱）はいつも手前。1px＝1.25 単位・基準の高さ 1024
  - 壁ぞいの斜めの家具（花の段・左の低い棚・姿見）は前にしか立てないので、人がいつも手前に描かれるようにした
- 部屋の id：`florist`（花屋）・`tailor`（仕立て屋）。住宅A の扉 → florist、住宅D の扉 → tailor。住宅B・E は今の民家のまま（`house-a`・`house-d` の地図はなくした）
- **セーブ version 24**：セーブの場所が `house-a`・`house-d` の中なら、新しい部屋の入口へ
- 歩ける所：床の上だけ。入口は手前の真ん中（柱の間）。カウンターの奥・仕立て屋の布の台の奥（小さなすき間）・右のトルソーの丸い敷物の上にも回れる
- 店番：マルタ（花屋）・ロザリー（仕立て屋）は真ん中のカウンターの奥（見た目の足もとは絵の (768, 482)。天板の奥の線より約65px手前で、腰から上が見える）。
  話しかけるのはカウンターの手前の床から。丸いす（カウンターの右はし）には重ならない
