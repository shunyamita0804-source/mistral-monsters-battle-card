# 指示書 AY2：テオの3枚コンボの直し（2026-11-05）

指示書の原本 `design-parts/card-names-20261105/00_instructions_AY2_20261105.md`。ブランチ `ay2-teo`（main に取り込む・**公開はしない**）。

## 直したこと

1. テオのデッキの α・β・γ を2枚ずつ（AY の3枚をやめた）
2. 取っておくのは α・β・γ それぞれ1枚まで（2枚目はふつうに使う・マナにする）。1種類しか手札に無いうちは取っておかない（技としても、マナにしないことも）。危ないときは取っておかない
3. 取っておくと使える技が0枚になる手番は、取っておくのをやめてふつうに使う（`ai.ts` の chooseAction）
4. lifeScale を 1.60 に戻し、**デッキで強くした**（`dungeons.ts` の `TEO_DECK`。`aceCopies` で技ごとの枚数を決められるようにした：0 なら入れない）

## 試した組み合わせ（目安のプレイヤー A・3箱 × 1000回。`docs/design/ay2-teo-20261105/`）

目標：勝つ割合 13±3％・山札切れ 25％ 以下・コンボを使った対戦 20％ 以上（優先：山札切れ → 勝つ割合 → コンボ）

| 組み合わせ | lifeScale | 勝つ割合 | 山札切れ | コンボの対戦 |
| --- | --- | --- | --- | --- |
| AY のまま（参考） | 1.82 | 10.7 | 50.2 | 28.4 |
| 直し1〜3（デッキはそのまま） | 1.60 | 16.7 | 26.1 | 0.3 |
| D1：弱い技を減らし強い攻撃を増やす | 1.60 | 16.0 | 28.8 | 0.2 |
| **D2：D1＋守りを減らし強い攻撃をもっと（採用）** | **1.60** | **14.4** | **9.8** | **0.3** |
| D2＋1種類でもマナにしない（指示書の外） | 1.60 | 20.0 | 11.7 | 0.6 |
| D2＋1種類でもマナにしない・危ないときも | 1.60 | 31.5 | 14.9 | 0.7 |
| D2＋α・β・γ 3枚ずつ（指示書の外） | 1.60 | 14.2 | 9.2 | 1.3 |
| D2＋α・β・γ 3枚ずつ＋1種類でもマナにしない | 1.60 | 21.9 | 12.5 | 1.5 |

- **D2 で山札切れ（9.8％）と勝つ割合（14.4％）は目標に入った。コンボを使った対戦は 0.3％ で目標（20％）に届かない**ので、指示書のとおりここで止めた
- コンボが起きないわけ：α・β・γ が2枚ずつ（60枚中6枚）で、1種類だけのうちは取っておかないので、2枚目が来る前に1枚目を使ったりマナにしたりする。対戦も短くなった（平均 25.7 手番。AY は 29.5）。AY の 28.4％ は「3枚ずつ・1枚でもマナにしない・ライフ 1.82 で長い対戦」がそろっていたため
- D2 の決着：倒して勝ち 14.1・山札切れで勝ち 0.3・倒されて負け 76.1・山札切れで負け 9.5（％）

## 要確認

1. コンボの見せ場（20％ 以上）をどう出すか。山札切れ・勝つ割合を守ったままでは、今の考え方では届かない。案：
   - テオの手札の補充や「システムチェンジ／システムチェック」を α・β・γ を探すのに使わせる（CPU の考え方を足す）
   - 最初の手札に α・β・γ のどれかを入れる（ボスだけの決まり）
   - コンボの条件・マナを軽くする（カードの数字は変えない決まりなので、ユーザー決定が要る）
2. テオのデッキで、システムチェック・のびのびガードなどを0枚にした（テオのデッキだけ。カードの数字は変えていない）
