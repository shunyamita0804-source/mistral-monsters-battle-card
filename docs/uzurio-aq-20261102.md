## 2. 技・新しい効果（決まりは `docs/battle-rules.md`「ウズリオの効果の扱い」）

## 3. サポート3枚

- **まいあがる風**（sup-12・F05・場・マナ3）・**しずまる大地**（sup-13・F06・場・マナ3）・**しずめの祈り**（sup-14・S08・すぐ・マナ1・1ターン1回のまとまり）。どれも「ふつう」・名前はデータのとおり
- 並びは足した順（今のカードの番号・絵の番号を変えないため、S08 も最後。図鑑 No.246〜248）
- 場の札：長い文のかわりに「全員が空中／全員が地上」（みちしおの「場が水中」と同じ考え方）
- **居場所の判定の点検**：居場所で決まる技はもとから `engine.ts` の `habitatOf` 1か所で判定していた（生まれつきの居場所を直接見ている所は無かった）。場のカードの居場所もここに入れた
- **みちしおとの関係**：みちしおも同じ場の1枠を使っているので、新しく出たほうが勝つ（まいあがる風／しずまる大地はみちしおを上書き。逆に、みちしおが出ると場の風・大地は持ち主の捨て札へ）
- しずめの祈り：サポートの場は出した人の捨て札へ。みちしおは水中がすぐ終わる。場が空なら使えない（「場にカードがありません」）
- 道具のパック（ガチャ）に3枚を「ふつう」の枠で足した（14種類）。最初の箱には入れない
- CPU：まいあがる風＝手札・山札に空中に強い技（うずまきショット・おおたつまき・あらし）があり、空中でない相手がいるとき。しずまる大地＝地上に強い技（急降下アタック・地ひびき）があり、
  地上でない相手がいるとき。しずめの祈り＝相手が出した場（みちしおも）か、自分に損な場。ふだんの CPU のデッキには入れない
