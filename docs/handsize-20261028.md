# 手札の大きさ・マナとダメージの数字・手札の印・枠の2倍（2026-10-28）

指示書：`design-parts/handsize-20261028/00_instructions_for_claude_code.txt`（手札の大きさ・数字 1.4倍）と、
同じ日のユーザー指示（手札の印を色と光に・技カードの枠を2倍の大きさに）。画面写真は `docs/design/handsize-20261028/`。

## 1. 手札のカードの大きさ（指示書 1章）

- `battleScreen.ts` の `HAND_CARD_W` を 80 → **90**。枚数が多くてもカードは小さくしない（前の `HAND_CARD_MIN_W` まで縮める決まりはやめた）
- 入りきらないときは重ねる（右のカードが左のカードの右側に重なる）。計算は `src/ui/components/handLayout.ts`（テスト `tests/handLayout.test.ts`）
  - 390 の画面：3枚までは重ねない。4枚から少しずつ重ねる。10枚でも1枚ずつ 31.6px 見える（カードの幅の 35%：マナの玉と左下の数字が見える）
  - さらに多いときも、1枚ずつ指で選べる幅 28px（`HAND_MIN_STEP`）は残す
  - 選んだカード・触っているカードは今どおり一番手前に出る
- 相手の手札（裏面）は今どおり（2026-10-26 のご指示で高さを増やさない大きさ。多いときは重ねる）
- **縦が足りない画面だけ 80 に戻す決まり**：作らなかった。この遊びの画面は、どの端末でも縦 844 の大きさで組んで縮めて表示する作り
  （`src/core/stageLayout.ts`）で、375×667（iPhone SE）では横が 474 に広がるだけで縦は 844 のまま。
  390×844 で幅 90 のまま手札・場・ボタンが重ならず切れないことを確かめたので、どの画面でも 90 のままで重なり・切れはない（写真 1・2）

## 2. マナの玉とダメージの数字（指示書 2章）

- マナの玉：`skillCard.ts` の `MANA_SCALE = 1.4`（玉の真ん中は LAYOUT の orb のまま。枠の玉の台を覆う）。数字だけのときの字も 1.4倍（15.4cqw）
- 数値の欄（`skillCard.ts` の `VALUE_FONT`）：ダメージ・軽減の数字 21cqw（手札用 22cqw）、盾 8.4cqw（手札用 9.8cqw）、短い文字 8.5cqw（手札用 9.5cqw）
- 欄からはみ出すときは、その端末の字の形で幅を測って、収まる大きさまで下げる（`src/ui/components/valueFit.ts`。欄の幅の 90% に収める。テスト `tests/valueFit.test.ts`）
  - 2けたの数字・「サポート」の4文字・英語の長い語は自動で小さくなる
  - 防御の「盾と -3」は、盾と数字を同じ割合で小さくして1行に収める
- 大きなカードの「ダメージ」「軽減」の小さい字は、数字と重ならない（写真 3）
- マナの玉の絵（`mana_*.png`）は 57px の小さな絵のまま大きくしている。iPhone と同じ細かさの写真（3倍）では、少しやわらかいがぼやけては見えない

## 3. 手札の印（ユーザー指示）

- トゲのある古い飾りの枠の絵（`hand_selected`・`hand_mana`・`hand_unusable`・`hand_mana_tag`）は重ねない（絵のファイルは残っているが使っていない）
- `uiParts9.css` の「8 手札の印」：
  - 使えない：カード全体を灰色にくもらせて少し暗く（`grayscale(0.85) brightness(0.6)`）
  - 選んだ：持ち上げて、まわりを金色にやわらかく光らせる（場のモンスターの光る印と同じ）
  - マナにする：持ち上げて、まわりをマナの玉と同じ水色に光らせる。上に小さな「マナ」の札（トゲのない丸い形）
  - 使えないカードを選んだときは、灰色のまま金色に光る

## 4. 技・サポートカードの枠を2倍の大きさに（ユーザー指示）

- `npm run art:skillframes`（`tools/art/skillcard_v3_build.py`）で、LAYOUT の **2倍**（縦長 506×764・手札用 416×420）の **webp（品質90）** を書き出す。
  前の `frame_*.png` は消す。62枚の合計 2.51MB（前の PNG は 4.66MB）。画面ではカードいっぱいに出すので、大きさ・位置（LAYOUT）は変わらない
- 分類のアイコン（拳・本・盾・羽・星）は、v3 の分類ごとの原本（4倍）から札の中を切り出して使う（前の 74px のアイコンを2倍に引き伸ばすとぼやけるため）。
  原本ごとに横幅がちがうので、銀の枠の札の位置を手がかりに、いちばん合う位置を探して切り出す
- `tools/art/skillcard_v5_monster_color.py` は倍率（`--scale=2`）とアイコンの差し替えを受け取れるようにした（`build()`）
- テスト `tests/skillFrames.test.ts`（すべて webp・そろっている・ちょうど2倍・合計が 4.6MB より小さい）

## 5. 確認用のボタン

- 対戦の確認用のボタン（`?qa=1` のときだけ）に「QA:手札+1」（山札の上から1枚を手札へ）を足した。手札が7枚・10枚のときの並びを確かめるため
- 確認用のボタンが4つになって画面の右にはみ出したので、折り返して並ぶようにした（`battle.css` の `.battle__qa`）
