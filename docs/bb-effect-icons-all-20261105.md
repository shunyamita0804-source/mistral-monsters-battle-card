## 【1】【2】アイコンの組み立て

- 正式の技で効果の文があるもの **132枚すべてをアイコンに**した（BA の49枚＋今回の83枚）。画面のカードに効果の文は出ない
- 1つのアイコン＝**本体1つ＋右上の小さな印（0〜2つ）＋右下の札（0〜1つ）**。本体が2つ要る効果は2つ並べる（`src/ui/effectIcons.ts` の表・`src/ui/components/fxIcon.ts` が重ねる）
- 新しい本体：E15 回避・E17 手札が減る・E18 見る・E21 引く／入れかえる・E24 反動（指示書の6点）、B11 回復・E13 場の効果（AZ の原本から）。小さな印 M01 味方に
- 小さな印：M01 味方に・S13 この相手だけ・倒れた印・T01／T02／T03・こぶし／本（分類の印）・B09（ためているとき）
- 数字の札：N01 の札に、＋n・−n は状態の札と同じ数字の絵（＋は緑・−は赤）、2+・3+・×2・≤1・3 は金の字
- 時計の札（次のターン）：場の残りの手番と同じ N02 の札に「1」。**右下（札の場所）に出した**（※ 下の表。時計だけを右上の小さな印にすると小さすぎて見分けにくいため）
- 押したとき：アイコン（帯の場所）を押すと、**その技の効果の文（今の文のまま）**を小さく出す。同じアイコンの技どうし（くしゃみとかぜのり など）は、この文で違いが分かる（BA ではアイコンの意味だった）
- ルールの窓「アイコンの見方」に、新しい本体のアイコン・小さな印・札の読み方を足した（日本語・英語）
