# 指示書 BG：対戦の結果画面（WIN / LOSE / DRAW）と勝ち・負けの曲（2026-11-05）

ブランチ `bg-result-screen`（**main には入れていない**。指示書に「main に入れてよい」が無いので確認待ち。**公開はしない**）。
指示書と素材の原本は `design-parts/result-screen-20261105/`（無改変）。

## したこと

- 結果画面（`battleScreen.ts` の `resultOverlay`・見た目は `src/ui/styles/resultScreen.css`）を作り直した。上から
  1. **相手の段**：左に相手の顔（`result_opponent_face_frame` の中。顔の角は枠の内側の窓に合わせて丸く切り抜く）、右に名前とひと言の窓（今の `window_result` の金の枠を使い回し）
     - ひと言：対戦の終わりのひと言（NPC バトルセリフ 43 名の npc_win／npc_lose・切り札の最後の撃破）。**結果画面の間は吹き出しには出さない**。文節の区切りでだけ改行（phraseText）
     - 引き分け：勝ち・負けのひと言が無いので、ひと言なし（名前だけ）。前は勝ちのひと言を出していた
  2. **WIN／LOSE／DRAW の文字の絵**（日英とも同じ絵）。判子のように 1.45 倍から縮んで止まる（0.3 秒）。ふだんは**帯なし**（帯ありは比べる用 `:root[data-result-band='on']`）
  3. **主人公の勝ち・負けの絵**（今の hero_*_win／lose。引き分けは出さない）
  4. 「◯手番」の小さい文字・山札切れの文と「続ける」ボタン（今のまま）
- 曲（`src/ui/bgm.ts`）
  - 結果画面が出たら、対戦の曲を 0.5 秒で小さくして止めてから、勝ち＝`battleWinJingle`・負け＝`battleLoseJingle` を1回だけ（`playAfterStop`）。引き分けは無音
  - 前の2秒の効果音（`battleWin`・`battleLose`）は結果画面では鳴らさない（ファイルは残す）
  - 「続ける」を押したら 0.3 秒で小さくして止める（`bgm.stop`）。次の画面の曲は、その画面が鳴らす
  - 大きさはバトルの曲と同じ合わせ方（gain 0.36）。設定の BGM の音量に従う
- クレジット：オプションの「素材のクレジット」（`options.creditsText`）に2曲を足した。記録は `docs/audio-credits.md`
