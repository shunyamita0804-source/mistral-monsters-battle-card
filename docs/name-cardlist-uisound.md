## 1. 名前を決める

- 出す所：主人公（男・女）を選んだすぐあと（導入が始まる前）。前のセーブ（名前なし）は、次に「続きから」を押したとき1回だけ
- 部品：`src/ui/components/namePrompt.ts`（見た目は `src/ui/styles/nameCardList.css`）。決まりは `src/game/player/playerName.ts`（画面に依存しない。テスト `tests/playerName.test.ts`）
  - 窓（金の枠の絵）の中に、ミレイユの顔と「あなたの名前を教えてね。」、入力欄、「決定」
  - 入力欄はスマホのキーボードで入れる（50音の文字盤は作っていない）。入力欄の文字は 20px（iPhone で入力欄が拡大されないよう 16px 以上）
  - キーボードが出たら、`visualViewport` で見えている高さを調べ、入力欄と「決定」が隠れないように窓を上へずらす。足りなければ顔を小さくして説明の1行を省く
- 決まり
  - 最大8文字（見た目の1文字＝1文字。`Intl.Segmenter`）。漢字の変換中は切らず、変換が決まってから8文字にそろえる
  - 前後の空白（半角・全角）は消す。絵文字・`< > / \ & " ' `` ` ``・改行などの見えない文字は入らない（入れても消える）
  - 1文字も無いときは「決定」が灰色（押すと ui_disabled）
  - 「決定」→「○○ でいい？」はい（ui_decide）で決まり／いいえ（ui_cancel）で入力に戻る
- セーブ：`player.name`（`SAVE_VERSION` 21 → 22。前のセーブは `name: null` を足して読む）。読むときもおかしな名前は直す（空なら null）

### 名前を出す所（「あなた」の代わり）

| 所 | 出し方 | 8文字で入るか |
| --- | --- | --- |
| 対戦の先攻・後攻を決める画面の上の VS（自分の札） | 名前 | そのまま入る |
| 対戦の記録の文のうち、だれの手札かを言う文（吠える・いたずら） | 名前 | 文なので折り返す |
| 大会の受付（参加する前）のあいさつ | 「○○さん、大会会場へようこそ。ランクは E です。」 | そのまま入る |
| 大会の総当たり表（受付の画面・会場の壁の板の窓） | 名前 | **6文字以上は文字を小さくして2行**（前半・後半） |
| トーナメント表（C〜S）の自分の札 | 名前 | **6文字以上は文字を小さくして2行** |
| 総当たりの順位表（3試合のあと） | 名前 | 折り返す（写真は撮っていない） |
| 名刺図鑑のいちばん上 | 「○○の名刺ファイル」（新しく足した1行） | そのまま入る |

変えていない所（役割を表す所・台本のままの所）：

- 対戦の「あなた／相手」の札、「あなたのターン」「あなたの勝ち！」などの帯・記録の文（役割の言葉なので今のまま）
- 導入の台本（S01〜S07）の台詞：台本に主人公を名前で呼ぶ台詞が無いので変えていない
- ダンジョンの人などの話し言葉の「あなた」（「森はまだ、あなたを見ているところよ」など）：話し言葉として自然なのでそのまま
- 冒険の記録（ベッド）の板：絵に名前の欄が無いので出していない

まだ名前が無いとき（前のセーブで、名前の窓を出す前）は、今までどおり「あなた」と出す（`heroName()`。`src/i18n/content.ts`）。

## 2. 取得カード

- 部品：`openCardList(parent, { cardIds, title?, onClose? })`（`src/ui/components/cardListView.ts`）。並べ方は `receivedCardList()`（`src/game/cards/receivedCards.ts`）
  - 上に選んだカードを大きく（今のカードの絵の部品 `createCardView`）、名前・枚数・分類・マナ・効果の文。下にもらったカードの一覧（一覧だけスクロール）
  - 並び：モンスター（もらった順）→ 技カード（もらったモンスターの順、同じモンスターの中は番号の順）→ サポート。見出しに枚数（「技カード（48枚）」）
  - 最初は1行目（モンスター）を選んだ状態。行を押すとそのカードを上に出す。「閉じる」で次へ
- いまつないでいるのは、管理局で箱を選んだあとだけ（「○○ を受け取った！」の窓の OK のあと → 取得カード → 受付のお礼の台詞）
- ダンジョンの勝ち・宝箱・ガチャの結果で使うときは、もらったカードの ID の並びを `cardIds` に渡すだけ（まだつないでいない）

## 3. ボタンの効果音

- 音：`assets/audio/se/ui/ui_tap|ui_decide|ui_cancel|ui_disabled.mp3`（届いた .mp3 を無改変）。`src/ui/sound.ts` の `SE_REGISTRY`（`uiTap` など）
  - 今の効果音と同じしくみ（Web Audio。iPhone で遅れない・ほかの音を止めない）。設定の効果音の音量に従う
  - 届いた音はほかの効果音より大きめなので、0.4 倍（押せないの音だけ 0.48 倍）にした
- どのボタンに何を鳴らすか：`src/ui/buttonSound.ts`（画面ごとには書かない。押されたボタンから決める）
  - 前にあった「ボタンを押すと鳴る小さな『コッ』（その場で作った音）」はやめて、この4つに置きかえた

| 音 | ボタン |
| --- | --- |
| ui_tap（ピッ） | ふつうのボタン全部：メニュー・タブ・一覧の行・設定・「最初から」・ページをめくる・人に話しかけた・取得カードの行・箱やガチャのパックを1回目に押して選んだとき・主人公の札の1回目・対戦のメニュー／ルール／降参／経過の1行・モンスターを押して詳しく見る |
| ui_decide | 「はい」「OK」「決定」「続きから」・金色の目立つボタン（買う・参加する・対戦する など）・ブースターの箱を買う・主人公の札の2回目・ガチャのパックの2回目・対戦の「攻撃終了」「ターン終了」「守備しない」「守備を終える」・結果の「続ける」・対戦のヒントの「わかった」 |
| ui_cancel | 画面の上の「戻る」・「いいえ」・「閉じる」・「やめる」・「タイトルへ戻る」・取得カードの「閉じる」 |
| ui_disabled | 押せない（灰色の）ボタン（名前が空のときの「決定」など） |
| 鳴らさない | 対戦のカードの操作（手札・「使う」・選んだカードの「やめる」・「マナにする」・守りのカード・技の相手のモンスター・使ったカードを大きく見せる所）、ガチャの「自動でまわす」（歯車の音がある） |

- 二重に鳴らさない：押したボタンの処理の中で、ほかの効果音（扉・門・レジ・宝箱・ガチャのパックを開ける・先攻後攻のカード・箱を決めたときの音など）を鳴らしたときは、ボタンの音は鳴らさない
- 決め方の順（`buttonSoundKind`）：`data-se`（tap・decide・cancel・none）→ 対戦の手札は鳴らさない → 押せない → 文字が「戻る・閉じる・いいえ・やめる」→ 文字が「はい・OK」か金色のボタン → ほかは ui_tap

## 4. 手札は最大9枚

- `BATTLE_RULES.maxHand = 9`（`src/data/rules.ts`）。引く効果（2枚引くサポート・考える など）で9枚を超える分は、引かずに山札の上からそのままマナにする（`engine.ts` の `drawUpToMax`）
  - 記録の文：「カードを1枚引いた。」のあとに「手札がいっぱい（9枚）なので、山札の上から1枚をマナにした。」
- ターンのはじめの「5枚まで引く」・山札が足りないときの負け（引く枚数が山札より多ければ負け）は今のまま。相手の CPU も同じ（同じ処理を通る）
- テスト：`tests/handLimit.test.ts`（9枚のとき引かずに全部マナ・8枚なら1枚引いて1枚マナ・7枚なら2枚とも引く・山札が足りなければ負け・CPU も同じ・考える）
