## R2 カレンダーの1段目：年と月

- **セーブの版 28 → 29**（理由：年と月を覚える欄 `calendar` を足したため。前のセーブは「1年目 4月」として読む）
- 決まり（数値は `src/data/calendar.ts`。仮）・計算（`src/game/calendar/calendar.ts`）
  - 「1年目 4月」から始まる。**4月になるたびに年が1つ進む**（1年目＝4月〜翌3月。指示書に書いていなかったので、始まりの月に合わせた）
  - 1か月進むのは3つだけ：ダンジョンから街に戻ったとき（ボスを倒した・3回負けて戻された・帰還の羽根）／大会が終わって景品を受け取ったとき（優勝でも負けでも・棄権でも）／家のベッドで「寝る」
  - 季節：春＝3〜5月・夏＝6〜8月・秋＝9〜11月・冬＝12〜2月
- 画面
  - 街と部屋の左上、場所の名前の札の下に日付の札（`src/ui/components/calendarArt.ts` の `datePlate`・見た目 `src/ui/styles/calendar.css`）。ダンジョンの中には出さない。
    月が変わる演出を出すまでは前の月のまま（`GameStore.displayCalendar`）
  - 月が変わるとき：月の帯に「5月」（約1.5秒・タップで早送り）。3・6・9・12月は先に季節の街の挿絵を画面いっぱいに出してから帯（`playMonthChange`）。
    ダンジョンから戻ったときは、戻ったお知らせのあと。大会は景品のお知らせのあと（受付の画面の上）
  - ベッド：「寝る」「セーブ」「やめる」（2026-10-30 指示書 T3 で「ロード」をなくした：セーブはいつも自動・バックアップからの復元は設定の画面だけ）。寝る →「1か月休みますか？ はい／いいえ」→ 夜の挿絵 → 暗転 → 月の帯 → 家の中で朝（「よく眠った。」）。体力などは変わらない
    - **セーブ＝これまでのベッドの画面**（記録の板・セーブのボタン・設定・タイトルへ・セーブを消す）。「寝る」とまぎれないよう、ボタンの字を「休む（セーブする）」から「セーブする」に
  - 大会：公式戦は 3・6・9月だけ。ほかの月は受付が「次の公式戦は ○月です」、12月は「12月はチーム戦の月です」と言って受け付けない（参加のボタンは押せない・理由を赤い字で）。
    出場の条件に「そのランクで開いているダンジョンのボスをすべて倒していること」（`RANK_BOSS_DUNGEONS`。新しいダンジョンはそのランクの一覧に足すだけ）。足りないと「○○のボスをまだ倒していません」
  - 管理局の掲示板（`src/ui/components/noticeBoard.ts`）：「大会のお知らせ」。紙2枚（3・6・9月 公式戦＝いまのランクの大会と条件／12月 チーム戦＝条件 C ランク・霧の廃坑）。
    出られないものは錠前の紙。今月の行事に「今月」、次の行事に「次は ○月」。「戻る」で閉じる
  - 英語：月の名前は英語の月名（Year 1 · April など）
- テスト：`tests/calendar.test.ts`（13）・`tests/gameStore.test.ts`（月の演出を1回だけ）。大会のテストは `tests/support/cupReady.ts`（6月・ボスを倒した）で条件を満たして動かす
- 写真：`tools/e2e/calendar_shot.cjs`（街の日付・ベッド・季節の挿絵・受付・掲示板・ダンジョンから戻る。W・H・LANG=en・ONLY）
