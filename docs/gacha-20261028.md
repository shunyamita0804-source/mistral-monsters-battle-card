# カードショップのガチャ（2026-10-28 作り直し）

指示書：`design-parts/gacha-20261028/00_instructions_for_claude_code.txt`（ZIP「Mistral_Gacha_ClaudeCode_20261028」。絵・お試しページ・画面写真も同じフォルダに無改変で保管）。

## 流れ

1. 販売機を調べる（またはショップの店員の「ガチャ」）→ **シリーズを選ぶ画面**（背景 `select_bg`）
   - 6つのパックを3列×2段。下に「○○のパック」「○ / 15 そろった」
   - 1回タップで光って少し浮く、同じパックをもう1回で決定 → 値段の確認（はい／いいえ）→ 払って機械の画面へ
   - 下に「提供割合」（2行だけ：モンスターカード 1パックに5％／技カードは技によって出やすさがちがう）。2026-10-30 指示書 V から「モンスターカード：まだ持っていないときだけ、1パックに5％」
2. **機械の画面**（`src/ui/components/gachaMachine.ts`）
   - 上：シリーズの名前・「提供割合」・「パックを選び直す」（払う前だけ）、ラインナップ15枠（技14＋モンスター。持っているカードは絵、まだのものは「？」。モンスターの枠は金のふち）
   - ラインナップは払う前の持ち物で描く（払ったあとの中身が先に見えないように）
   - つまみ（`knob_base` は動かない・`knob_dial` が中心 (650,1000) のまわりに回る）を指で時計まわりに1周。反対まわりは進まない。18°ごとに「カチッ」（`sound.ratchet`）。「自動でまわす」もある
3. **まわし終えたら**：ガシャン（`chestUnlock`）で機械が小さく揺れ、ガラスの中のパックが1つ落ちる → 取り出し口が開く → 取り出し口へ寄る（0.6秒。2.75倍）→
   細かい絵（`outlet_zoom_back`・`outlet_zoom_front`）に切り替え → パックが寝た形で奥から手前へすべり出て、手前のふちの下からはみ出して止まり、ふわっと光る（`cardSlide`）→「タップして取り出す」
4. **開ける**（`src/ui/components/gachaOpen.ts`）：パックが大きく出る。上から17％の所に点線の目印。上のほう（上から45％まで）を横になぞると光の線が伸び、パックの幅の60％で破れる → `open_burst` と `packOpen`
5. **めくる**：5枚が重なって出て、いちばん上が表に返る（`cardFlip`）。タップで左上へ、スライドならその向きへ飛び（`cardDraw`）、次が返る。最後の1枚の前は0.9秒おいて「最後の1枚…！」
   - 技＝今の技カード（マナ・ダメージ・技名・説明入り）、モンスター＝バトル用カード
   - 飛ばしたカードは下に小さく並べ、初めてのカードに「NEW」。押すと詳しい表示
   - レア枠：光の筋と金の光・`cardReveal`（文字は出さない）。モンスター：画面が白く光る・`open_burst`・`reward`・「モンスターカード！」
   - 全部めくったら「もどる」（シリーズを選ぶ画面）と「もう1回」（同じシリーズ。機械の画面に戻って値段の確認。「いいえ」なら払う前の機械の画面＝「パックを選び直す」が出て、つまみをさわると値段の確認）

## 中身と確率（すべて仮。`src/data/economy.ts` の `GACHA`・`GACHA_SERIES` だけで変える）

- 1シリーズ＝1モンスター（正式の技14種＋モンスターカード＝15枠）。いまは6シリーズ（ソラモ・ガウル・ラズック・ノビトン・ミュロル・カルシェル）。すべて最初から選べる
- 値段はどれも 150G・1回5枚・中身は無限・天井なし。同じカードの4枚目からもそのまま持つ
- 1枚ごとに技を重みで選ぶ：ノーマル1種＝4、レア1種＝1。1パックに5％でモンスターカード（5枚のうち1枚が替わる）。
  2026-10-30 指示書 V：**そのモンスターのカードを1枚も持っていないときだけ**。持っていれば、モンスターの抽選をせず技14種だけ（天井なし。これから増える「大会で開くガチャ限定のモンスター」も同じ）
- 開ける順：ノーマル → レア → モンスター
- レア枠（技の名前で指定し、ID は今のデータから引く。見つからない名前はテストで分かる）

**2026-10-29 夜（ユーザー決定）**：「そのモンスターのいちばん大きい攻撃はレア」を足し、どのモンスターもレアを3つにそろえた。
