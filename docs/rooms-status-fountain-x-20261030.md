- 原本 `design-parts/battle-status-20261030/`（256×256）→ `assets/images/ui/battle/status_{frozen,energy,no_evade}.webp`（64×64 に縮めただけ）

## C. 噴水の水

- 原本 `design-parts/town-20261028/fountain-overflow-20261030/`（600×750・3コマ）。`tools/design/town2026_build.py` の `fountain_overflow`
- 水の輪（受け皿のふち）の幅 約200px は受け皿のふち（約210px）とそろっているので倍率はそのまま。輪の真ん中を受け皿のふちの真ん中に合わせて噴水の手前に重ね、
  受け皿の水の面・とがった飾り・下の池の手前のふちに隠れる所だけ消した。しぶきと同じ loops・同じ速さ（220ms）でくり返す
- 1コマ目は少し薄い（見えている所の不透明さの平均 約206、ほかは 約236）ので、くり返したときにちらつかないよう、1コマ目の不透明さだけほかにそろえた（色は変えていない）
- 街を作り直して変わったのは、水の3コマを足した所だけ（ほかの街・部屋の絵は1バイトも変わらない）
