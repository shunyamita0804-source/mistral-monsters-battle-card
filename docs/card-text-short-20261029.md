# カードに書く効果の文を短くする（2026-10-29 夜）

ユーザー指示：大きなカードの効果の帯で、字がとても小さくなるカードがある（例：ガウル14 高速飛行・プカリム10 おいかぜ）。
ジオルと同じやり方で、カードに書く文だけ短くする。データの JSON の文とルールの決まりは変えない。一覧（2回）を見せて承認をもらってから直した。

## したこと

- 短い文の表：`src/data/skillCardText.ts` の `SKILL_CARD_TEXT`（技の ID → 文）。`officialSkills.ts` の `officialSkill` が effectTextJa に入れる
  （大きなカード・カードの詳しい画面・図鑑・対戦中の説明。手札の大きさのカードは、もともと効果の文を出さない）
- ジオルの `GEOL_CARD_TEXT`（05・09・10・11）もこの表へまとめた（geol.ts からは消した）
- 英語（仮訳）も短い文に：`src/i18n/contentEnOfficialDraft.ts`
- 決まり
  - 大きなカードの帯に、いちばん大きな字（4.6cqw）のまま2行に入る。数字の言い直しはしない（ダメージ・マナはカードの別の所に出ている）
  - 防御の技（20枚）は、軽減の数（左下の欄）を書かず「ちから技に効く」「かしこさ技に効く」「ちから技・かしこさ技に効く」の形。
    うけとめる（左下「0に」）も「ちから技に効く」。条件のあるスリップガードは「マナ3以上のちから技・かしこさ技に効く」。かばう（ジオル11）は今の文
  - 回避は「マナ2以上の〜を回避」「マナに関係なく、〜を回避」の形
  - 「重複不可」は「重ねられない」
- 決まった36枚（防御20枚・そのほか16枚）とジオル 05・11 の文は `skillCardText.ts` にそのまま（確かめ方 `tests/skillCardText.test.ts`）
- 字の大きさ：36枚のうち34枚はいちばん大きな字。ユーザーが文を決めた いたずら・しめったはだ は 98%（4.5cqw）。
  英語は いたずら・ちょうはつ・じならし の3枚が 89%（4.1cqw。意味を欠かさないため）。ほかはいちばん大きな字
