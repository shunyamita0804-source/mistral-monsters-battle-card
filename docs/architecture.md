## 層の分け方

| 層 | 場所 | 内容 | DOM |
| --- | --- | --- | --- |
| 設定 | `src/config/` | 正式名称・論理解像度・画面ID一覧 | 使わない |
| 仮データ | `src/data/` | カード・ルール値・パック/価格/提供割合・大会・マップ・ダンジョン/敵編成・欠片の場所。**すべて仮**で、正式データが届いたらここを差し替える | 使わない |
| 基盤ロジック | `src/core/` | 画面の拡大縮小計算、画面遷移（Router）、素材パス | 使わない |
| ゲームロジック | `src/game/` | バトル（ルール・AI）、デッキ検証、ガチャ、大会・ダンジョン・欠片の進行、セーブ、歩行の当たり判定・経路探索 | 使わない |
| UI | `src/ui/` | 画面・部品・CSS・セーブの読み書き（`GameStore`） | 使う |

`src/core/`・`src/game/`・`src/data/` は DOM に依存しない純粋な TypeScript で、`tests/` の Vitest でテストしている。
UI はセーブを直接書き換えず、`GameStore.update(純粋関数)` で変更する（変更のたびに保存）。

## カードバトルのルール（`src/game/battle/`）

- `engine.ts`：状態（双方のモンスター3体・ライフ・山札・手札・捨て札・マナ・手番・防御待ち・勝敗・記録）と `applyAction()`
  - 行動：`useCard`（技を使う：使うモンスター・対象を指定）／`defend`（防御・回避カードを1枚ずつ何枚でも、null で守備を終えてダメージ計算）／`endAttack`（攻撃を終えてマナ化へ）／`convertToMana`（手札1枚をマナに・何回でも）／`endTurn`（マナ化中のみ）
  - `cardUsability()`：使用不可の理由（マナ不足・行動済み・倒れている・守備は攻撃を受けたときだけ・狙われたモンスターのカードだけ・能力が違う・防御不可/回避不可 等）
  - ルール上できない行動は無視して状態を変えない（二重タップや AI の誤りで壊れない）
  - 乱数はシード付き（同じシードなら同じ展開）
- `ai.ts`：相手の思考（回復 → 倒せる相手を攻撃 → 強い攻撃 → マナ/ドロー → 攻撃終了。マナ化は守備1枚と次に使う技1枚を残して残りをマナに。守備は大きいダメージなら回避、それ以外は防御を重ねてダメージ0まで）
- ルールの数値は `src/data/rules.ts`（**仮ルール**。画面の「ルール（仮）」にも表示）

## 歩行（`src/ui/screens/worldScreen.ts`・`src/game/world/world.ts`）

- 街と部屋（家・となりの家・民家A〜E・ショップ・研究所・大会会場・練習場）は正式な絵。`tools/design/seimon_world_build.py` が部品を設計図どおりに並べ、
  背景の絵（`assets/images/maps/`）と `src/data/worldArt.generated.ts`（マス目・扉・家具の位置）を作る。`maps.ts` はそれを読んで出入口・家具の役割を決める
- マスは設計図の 32px（街は 126×126。2026-10-22 に 150×150 から詰めた）。表示は設計図の 0.5625 倍（1マス 18 論理px）。部屋は画面の高さに合わせて最大 1.35 倍に拡大
- ダンジョンは記号マップ（**仮マップ**。1マス 40 論理px）のまま
- 家具・人物は足元の高さで前後を決める（z-index）。人物の足元に影。場所を移るときは暗転し、絵を読み込み終えてから見せる
- 見せる倍率 `VIEW_ZOOM`（街 1.15・ダンジョン 1.5・部屋 1）で地図ごと拡大し、カメラが追う（遊び 14×18 論理px・進む向きへ 8% 先読み）。2026-10-24 改訂R2 フェーズ1
- 人のまわり（正式な絵の街・部屋）：人から1マス以内は通れない・2マス以内で話せる（右下のボタンが「話す」に）・3マス以内で主人公の方を向く（`world.ts` の `isNearNpc`・`nearestNpc`）
- 操作：画面のどこでも指を置いてすべらせると歩く（指を置いた所に半透明のスティック。**8方向**・角はすり抜けない）／すべらせずに地面をタップすると経路探索（8方向）で移動／
  人・家具・敵・宝箱をタップすると近づいて話す・調べる／右下の「しらべる」で正面（なければとなり）と足元を調べる（調べられる物のとなりでは光る）／PC は矢印キーと Enter
- 当たり判定：壁・建物・家具・人・敵・宝箱は通れない。敵にぶつかるとバトル。出入口・階段は踏むと移動（出ると同じ玄関の前に戻る）
- 歩行速度：231 論理px/秒（仮。2026-10-22 に 185 から 1.25 倍）。主人公は正式な歩行の絵（1コマ 216×288・足元 108,270）を、歩き4コマ＋立ち止まりの1枚のシート
  （`player_{male,female}_sheet.png`）にまとめて使う（画像を切り替えると iPhone で一瞬消えるため）。約7コマ/秒

## 序盤イベント（`src/game/story/`・`src/data/storyScenes.ts`・`src/ui/components/dialogue.ts`）

- 流れ：新しく始める（自分の家の中）→ 家から街に出ると、となりの家の女性（案内役・名前は未定）が声をかける →
  「練習してみる」なら北西のカード練習場へ自分で歩く（街の上に目的地を表示）→ 練習場で会話 → 練習試合 → 対戦後の会話 → 自由行動
- 「あとで」・スキップでも一本道にしない。案内役は街にいて、話しかければ誘い直す。練習テーブルはいつでも練習試合ができる
- 進み具合はセーブの `story.intro`（`notSeen`〜`completed`。意味は `storyScenes.ts` の先頭）。旧セーブは `deferred`（導入を突然始めない）
- 場面（台詞の順番・選択肢・終わりにすること）は `src/data/storyScenes.ts`、台詞の文は `src/i18n/messages/story.ts`（台本 V1・**仮**、日英）
- 会話の UI はミストラルモンスターズの画像（セリフ枠・名前の札・選択肢。`assets/images/ui/talk/`）。会話の絵は制作中のため「仮」の札。
  届いたら `dialogue.ts` の `PORTRAITS` に表情ごとに足す。街の案内役も仮の印（歩行16コマが届いたら差し替え）
- 練習試合：相手は `ENCOUNTERS['enc-practice']`（スターターと同じ3体・ライフ0.6倍・仮）。報酬・戦績なし。勝ち負けで進行は止まらない。
  最初の練習だけ、バトルの場面に合わせたヒントを1回ずつ出す（`src/game/story/battleTutorial.ts`。ルールは変えない）

## セーブ（`src/game/save/`）

- 1つのセーブにカード所持・通貨・パック解放・欠片・大会実績（参加中の大会を含む）・ダンジョン進捗（探索中を含む）・デッキ・現在地をまとめて保存（localStorage）
- `version` で形式を管理し（いまは 5。2→3 で物語の進み具合 `story` を追加、3→4 で街を作り直したため街・部屋にいた位置を主人公の家の前へ、4→5 で街を詰めたため街にいた位置を家の前へ）、古い形式は `MIGRATIONS` で変換。新しすぎる・壊れたセーブは退避（`...-unreadable-backup`）して上書きしない
- 読み込み時に `normalizeSave()` で型・範囲を確認し、`sanitizeLocation()` で矛盾した位置（ダンジョン外なのに探索中・通れないマスにいる など）を直す
- 二重決済・二重受け取り防止：購入・特別復元は「確認を開いたときに作る ID」で1回だけ処理（`processedTransactions`）。大会の景品は参加ID（`claimedEntries`）で1回だけ
- アプリがバックグラウンドに回ったときにも保存
