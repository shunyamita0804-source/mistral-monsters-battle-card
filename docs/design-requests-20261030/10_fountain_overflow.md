## いまの絵と困っていること

- 指示書 S2 で、しぶきの水柱をいちばん上の受け皿の真ん中（金の飾りの先）から出し、左右の筋が受け皿のふちに落ちるように直した
- 「受け皿から下の池へ落ちる水」は、今のしぶきの絵（`design-parts/town-20261028/part2_terrain_props/fountain_layers.png` の右の3コマ。左右に弧を描く形）では作れなかった。
  弧の先を下の池までのばすと雨のすじのように見え、くり返して足すと段がついた
- 今は下の池の水は動かない（水の輪の絵だけ）

## 依頼文（このままコピーして使う）

```
ミストラルモンスターズ バトルカードの街の噴水に重ねる、水のアニメーションを描いてください。添付の「今の噴水」と同じ角度（真上より少し手前から見下ろす）・同じ塗り（明るいファンタジーの手描き風、水は水色と白のきらめき）で。

描くもの：いちばん上の受け皿のふちから、ぐるりと水があふれて、下の池へ落ちる水（あふれ落ちる水のカーテン）。3コマでくり返す動き
- 上の受け皿の大きさ・位置は添付の噴水どおり。水は受け皿のふちの外側を、柱のまわりに円く落ちる（手前と左右がよく見え、奥は柱に隠れる）
- 下の池の水面に落ちた所に、小さな白いしぶきと波紋
- 噴水の台・柱・受け皿・池は描かない（水だけ。台の絵はゲームの今の絵を使う）
- 3コマとも同じ大きさ・同じ位置合わせ（受け皿の真ん中の位置が3コマで同じ）
- 背景は透明（PNG）

保存名：fountain_overflow_1.png・fountain_overflow_2.png・fountain_overflow_3.png（今の噴水の絵 fountain_layers.png の左の噴水と同じ倍率。1枚 600×750px 以内）
```
