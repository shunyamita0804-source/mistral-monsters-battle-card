# 依頼文：街の石の橋（正面向き・遠近なし）

写真：`01_stone_bridge_iphone.jpg`（ユーザーの iPhone。赤い丸）・`01_stone_bridge_now.jpg`（今の部品）。

## いまの絵と困っていること

- 今の石の橋は、部品のシート `design-parts/town-20261028/part2_terrain_props/bridges.png` の右の橋。手前が大きく奥が小さい遠近で描かれていて、
  4本の塔も手前の2本が大きく、床も奥へ細くなる。街の床（石畳）は遠近なしなので、橋だけ下り坂・ななめに見える
- 床の石の色・形も、まわりの石畳（`tile_street`）と少しちがう
- 道の途中なので外せない（新しい絵が届くまでそのまま）

## 依頼文（このままコピーして使う）

```
ミストラルモンスターズ バトルカードの街の部品を1つ描いてください。添付の「今の街の写真」と同じ、真上より少し手前から見下ろす正面向き（建物の正面がこちらを向き、奥行きは上へ）・同じ角度・同じ塗り（明るいファンタジーの手描き風、やわらかい影、金の飾り）で。

描くもの：小川を南北にまたぐ石の橋（1つ）
- 橋は画面の縦（上＝北の岸、下＝南の岸）にまっすぐ渡る。遠近なし：手前と奥で幅も塔の大きさも同じ。左右の欄干は平行でまっすぐ
- 四すみに、今と同じ紺と金の旗のついた白い石の塔（4本とも同じ大きさ）。塔の外側に街灯
- 橋の床は、添付の「街の石畳」と同じ色・同じ形の石（ベージュと灰色の不ぞろいな石）。床の上のはし・下のはしは石畳の道にそのまま続く（段差なし）
- 欄干の外側に、小川の上にかかるアーチ（石の面）は描かない（水はゲームで重ねる）
- 大きさの目安：横 1000px × 縦 1050px（塔の外のはしから外のはしまで）。床の幅（欄干の内側）は 約520px
- 背景は透明（PNG）。影・水・草・石垣は描かない

保存名：stone_bridge_front.png（2048×2048 以内、透明 PNG）
```
