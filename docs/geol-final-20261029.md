## 1. ジオルを正式に

- `mon-geol`・`skl-geol-01〜14` を確認用の一覧（`QA_MONSTERS`・`QA_SKILLS`）から、ふつうの一覧（`MONSTERS`・`SKILLS`）へ移した。
  図鑑の番号はプカリムのあと（No.106〜120。`cardNumbers.ts`）。ライフ 9・技14の数字は今のまま。確認用の「ジオルの試遊」（?qa=1）は残した
- 内部ランクは C → B（B の下の方）。画面には出さない。JSON の `monster_rank` は無改変のため C のまま（`src/data/geol.ts` のコメントに記録）
- 大きなカード（と対戦中の説明）の効果の文を短くした（`GEOL_CARD_TEXT`。JSON の文は変えない。英語の仮訳も短く）

  | 技 | 新しい文 |

  | 05 地ひびき | 相手全員に当たる（守りは1体ずつ） |
  | 09 じならし | 選んだ相手1体は、このターン次の攻撃を回避できない |

  ルールの細かい決まりは `docs/battle-rules.md`「ジオルの効果の扱い」と、ルールの画面の説明のまま
- 不具合の直し：対戦中の説明の枠（技を使ったときの左の欄）で、文が枠に入りきらないと下が切れていた（地ひびきが「防御・」で切れた）。
  入りきらないときは字を段階的に小さくし（`battleScreen.ts` の `fitSpotTexts`・`battlePs.css` の `is-fit-1〜3`）、それでも入らなければ枠の中を縦にすべらせて読める
- 仮ジオル（`mon-tmp-geol`・`skl-tmp-geol-1〜6`）はゲームから外した（グラントのデッキからも）。
  **セーブ version 23**：仮ジオルのモンスターカードは同じ枚数の `mon-geol` に置きかえ、技カードは消す（デッキの仮ジオルはジオルに。抜けた技の分は持っているカードで埋める）。
  名刺図鑑の記録・挑戦中の獲得も同じように直す。古いバックアップに入っていても止めない（`REMOVED_CARD_IDS`）
- ガチャのシリーズ・ショップの棚にはまだ入れていない（パック専用の絵と一緒に次の作業で）

## 2. 太古の遺跡を初期のダンジョンから外す

- 初期のダンジョンは精霊の森（地下3階）だけ。太古の遺跡は C ランクに上がったときに開く（氷の洞窟と同時。大会の報酬の窓に「新しいダンジョン発見」が2つとも出る）
- 遺跡は地下4階。中身は氷の洞窟と同じ段（`dungeonRun.ts`・`economy.ts`）

  | 項目 | 値 |
  | --- | --- |
  | 階ごとの強さ（floorLife） | 0.9・1・1.1・1.2 |
  | 1勝 | 25G |
  | 宝箱 | 25〜50G |
  | ボス | 初回 600G・2回目から 180G |
  | バトラー | ［カルシェル・ノビトン・ミュロル］［ノビトン・カルシェル・ソラモ］（氷の洞窟と同じ） |
  | 見えない番人 | ［カルシェル・ノビトン・カルシェル］（氷の洞窟と同じ） |
  | 仕掛け | なし（今のまま） |

  プカリムを使うのは精霊の森のバトラーだけ。地下4階の床と壁の絵は地下3階と同じ絵
- ボスのグラント：ガウル・ジオル（`mon-geol`）・ラズック、lifeScale 1.2
- 初回クリア：最奥の祭壇でジオルのモンスターカード1枚（今の受け取り方のまま）。このとき技カードは出さない。
  2回目から：ジオルの技カード1枚（ジオルの14技からランダム。`dungeons.ts` の `trumpReward`・`run.ts` の `bossRewardCandidates`）。宝箱の技カードもジオルの技
- すでに遺跡が開いている・クリアしたセーブはそのまま（閉じない）。遺跡の挑戦の途中のセーブは、そのまま続けられる（3階の次に4階ができる）

### 「最初は遺跡へ」のような案内の点検

画面の文字・台詞・チュートリアル・ヒント（`src/i18n/messages/`・`src/data/people.ts`・`storyScenes.ts`・`introV2.ts`）を「遺跡」「最初のダンジョン」で全部探した。
**「最初は遺跡へ」と案内している所は見つからなかった**（直した所はなし）。見つかったのは次のもので、どれも案内ではないのでそのまま：

| 場所 | 文 | 扱い |
| --- | --- | --- |
| 道具「遺跡の地図」（`items.ts`・使ったときの文） | 遺跡の地図を広げた… | どのダンジョンでも使える道具の名前。そのまま |
| フローラの肩書き（`people.ts`） | 遺跡探検家 | 森・遺跡のバトラーの人物。そのまま |
