### 目安との比べ（腕前 B が主）

- **腕前 B でいちばん良いのは T2**：3つの組み合わせが 45.5〜49.3%（V1 は 44.0〜49.3）。旅立ち×蒼海 44.0→45.5 で目安に入った。烈火×蒼海は 48.8 で、まだ「烈火が少し勝ちやすい」の向きにはならない
- T1 は B で蒼海が少し強くなる（旅立ち×蒼海 42.0・烈火×蒼海 44.5）。F1・TF は B で蒼海が強くなりすぎる（蒼海 58〜60%）
- 腕前 A では TF がいちばん近い（旅立ち×蒼海 45.5・烈火×蒼海 51.8・蒼海の山札切れ負け 44.4→33.3）。ただ 旅立ち×烈火 35.3 は蒼海では直らない
- **ただし T2 の良さは「みちしお」のおかげではない**（下）。はさむ・すなをほるを1枚ずつ減らして山札が少し変わったぶんの差と見ている

### CPU は みちしお をうまく使えているか → **ほとんど使えていない**

- CPU は「水で強くなる攻撃（タイダルクラッシュなど）が手札にあり、いま〜次の手番に使える」ときだけ みちしお を出す（`src/game/battle/ai.ts` の `chooseTide`）
- 蒼海で水で強くなる攻撃は タイダルクラッシュだけ。T2 は タイダルクラッシュを入れないので、**みちしおを一度も使わない**（ただの使わないカードが2枚になる）
- T1・TF でも、みちしおとタイダルクラッシュが同時に手札に来るのは 14対戦に1回くらい（0.07）。使ったのは 0.01〜0.03 回。
  タイダルクラッシュは ほとんど水の外で使われている（0.23回）。T1・TF の変化は「はさむ・すなをほる → 5ダメージの攻撃1枚」の入れ替えの差
- 「水の中で手札にとっておく」もしていない（0）
- みちしおを生かすには、(1) 水で強くなる技を蒼海に増やす、(2) CPU が みちしお を先に出して水を作っておく、のどちらかが要りそう（今回は変えていない）

## 2. 確かめ用の入口（iPhone で T1 の蒼海を遊ぶ）

- 設定 → QA用 → **「蒼海（みちしおあり）を試す（確認用）」**。または URL に `?qa=1&lab=soukai`
- 自分は T1 の蒼海（ミュロル・カルシェル・フォルン。みちしお 1枚・タイダルクラッシュ 1枚）。相手の箱（旅立ち／烈火）と腕前（B／A）を選んで「対戦する」
- 借りた山札で遊ぶので、自分のセーブのカード・山札・お金・記録は変わらない（対戦が終わると確かめ用の画面に戻る）。テスト `tests/soukaiLab.test.ts`
- 入口は `?qa=1` のときだけ出る。ふだんの遊びには出ない
- **セーブが無くても開ける**（ユーザー指示・2026-11-02 公開の前）：`?qa=1&lab=soukai` はそのまま、`?qa=1` のタイトル画面にも「蒼海（みちしおあり）を試す（確認用）」のボタン。
  セーブは作らない・書かない（主人公の名前・絵はふつうのもの）。セーブが無いときに開ける対戦は、借りた山札のものだけ（`src/ui/app.ts` の `screenWithoutSave`）
- 写真：`docs/design/soukai-ap-20261102/soukai_lab.jpg`（入口・選ぶところ・対戦の始まり）・`soukai_lab_nosave.jpg`（セーブ無しで開いて対戦・降参・結果）

iPhone での手順：

1. Safari で `https://shunyamita0804-source.github.io/mistral-monsters-battle-card/?qa=1&lab=soukai` を開く
2. そのまま確かめ用の画面が開く（セーブは要らない）。相手の箱と腕前を選んで「この組み合わせで対戦」
