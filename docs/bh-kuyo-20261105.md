# BH の直し（2026-11-05 ユーザー指示。ブランチ `bh2-kuyo`・main に入れた・公開はしない）

ユーザーは BH を合格にした。そのうえでの直し：

1. **みがわり**：代わりに受けた攻撃には、クヨウの防御・回避を重ねて使えない（−2 だけで完結。「みがわりで受けた攻撃には、守りを重ねて使えません」）。ジオルの かばう・フォルンの みがわりのふえ は今までどおり
2. **おはらい**：「味方1体の悪い状態をすべて消し、ライフ＋1（もとのLIFEまで）」（`purify` の `heal: 1`）。悪い状態が無くても使える。悪い状態も無くライフも満タンの味方しかいないときだけ使えない。
   CPU：悪い状態の味方がいれば先に。いなければライフの減った味方（ライフ半分以下でその手番に倒せる攻撃が無ければ攻撃より先、ほかは攻撃のあと）。効果のアイコンは回復＋味方に＋「+1」（【仮】のまま）
3. **悪い状態にじならし（回避できない）を足した**（`pinned`。おはらいで消え、まよけのふだで防ぐ）。※今のカードには じならし を持つ技が無い（指示書 AJ の作り直しで外れている）ので、試遊・対戦では起きない
4. **枠の色 #87649C**（カードの絵の枠の色）：`KUYO_COLOR`・バトル用カードの枠・技カードの枠・名前のロゴの帯・図鑑。パックは縁の藤色の帯（#9B82B7 くらい）だけを #87649C に寄せた（窓の中の絵・金の線・紺は変えない。`tools/art/kuyo_assets.py` の `band_tint`）
5. **ミニマップのスイッチの印**をほかの印と同じ大きさ（マスの3.4倍）に
6. **説明文**：「霧の奥から九つの目で見守る霊獣。悪いものをはらうと伝えられる。」／"A sacred beast that watches from deep in the mist with nine eyes. It is said to drive away evil."
