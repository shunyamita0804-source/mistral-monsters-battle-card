# 部屋4つ（大会会場・管理局・練習場・研究所）の新しい絵（2026-10-28）

指示書：`design-parts/rooms-20261028/00_instructions_for_claude_code.txt`（ZIP「Mistral_Rooms4_ClaudeCode_20261028」Part1〜3。部品・見本も同じフォルダに無改変で保管）。
カードショップ・主人公の家・となりの家・民家はさわっていない。

## 作り方

- 組み立て：`python3 -I tools/design/rooms4_build.py [確認画像の出力先]` → `assets/images/maps/rooms/room4_*.webp` と `src/data/rooms4Art.generated.ts`（数秒）
- 部品は 1536×1024 の同じキャンバス。shell（部屋の箱）は奥に敷き、家具は1つずつ切り抜いて足もとの y で人と前後を比べ、front（手前の低い壁と入口の柱）はいつも人より手前
- 大きさ：1px＝1.25 単位・基準の高さ 1024（カードショップと同じ。人の大きさがほかの部屋とそろう）。色の処理はかけていない
- 歩ける所：床の多角形と入口の通り道から、家具の足もと・入口の柱を除いたもの（`ROOMS` の `floor`・`passage`・`blocks`）
- 壁ぞいの斜めの家具（練習場の左のカウンター・研究所の飾り棚と実験台・管理局のランクの板など）は前にしか立てないので、前後の比べる高さを小さくして、前に立った人がいつも手前に描かれるようにした
- 調べる物は、となりに歩けるマスが無ければ下へ広げる（家具の手前の床から調べられる）
- 確認画像（歩けるマス・調べる物・人の所を見本に重ねたもの）は、引数に出力先を渡すと書き出す
- 前の絵：大会会場・練習場・研究所は `tools/design/seimon_world_build.py` で作らないようにした（`ROOMS4_IDS`）。管理局の前の部品（bureau-v01）と、使わなくなった古い絵のファイルは消した

- カウンター・机の奥に立つ人は、話しかけるマスを家具の一番手前（大会会場は左はし）に置き、見た目だけ奥にずらす（`maps.ts` の `drawDy`・新しく足した `drawDx`）。
  見た目の足もとは、天板の奥の線より約65px手前（腰から上が見える所。天板の線に置くとカウンターの上に浮いて見え、カウンターの高さぶん下げると頭しか見えない）
- 大会会場の左の壁の大きな紺の板は空のまま。位置は `HALL_ART.items.BOARD`（マス）に記録した（総当たり表を描くとき用。調べる物にはしていない）
- 研究所の機械（03）か実験台（04）は、欠片の特別復元を研究所へ移すときに使う予定（指示書「ブースターとカウンター」）
