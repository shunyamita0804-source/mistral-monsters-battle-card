## 変えたこと

1. **自分の番の大きなカードを大きく**（ユーザー選択「ア」）
   - 相手3体と自分3体のあいだを 43 → **16** に戻し、浮いた分を説明の欄に回した（200 → **227**。`battleScreen.ts` の `layoutCamera`・`FIELD_GAP`）
   - 大きなカードは欄の高さいっぱい（**140×212**。前は 123×186）。説明の箱は残りの幅（約 225）。文字の大きさは前のまま
   - 何も選んでいないとき（直前のカードを薄く・まだ無ければ点線の枠）・技を使った演出も同じ大きさ。技を使った演出は「誰が誰に」の1行を説明の箱の頭に入れた（前はカードの上に横長で、その分カードが 100×151 と小さかった）
2. **相手の番・守りの選択は、相手のカードを相手の側で大きく**
   - 守りの選択の間はカメラを `defense` にする：上の相手の大きなカードの欄に、相手の攻撃のカード（相手の番と同じ 176×266）と説明（「相手の攻撃！」「『かぎづめ』→ ガウルに ちから2」「いまのダメージ 2」「使えるカードの説明（マナ 5）」）。守りのカードを使うと「いまのダメージ」がここで変わる
   - 相手の手札の段は 0.3 秒でたたむ（相手3体・自分3体がその分だけ上へ動く）。相手の大きなカードの欄は大きさも位置も動かない（相手がカードを使った所と守りの選択でカードの位置が同じ 46+15 の所）
   - 自分3体の下に守りの選択の欄（たたんだ段と同じ 133）。守りのカードは手札と同じ **98 幅**（前は 76）。使えないカードは薄くして「使えない」と1行（理由はボタンの読み上げに残した）。多いときは手札と同じく重ねる（重ねたときは「使えない」はいちばん右のカードだけ。ほかは薄くするだけ）
   - 守りのカードの数値（−3・回避）はカードの絵に出ているので、下の文はやめた
   - 守りのカードを使った演出は、守りの選択の欄の大きさで見せる（相手のカードは上に出したまま）
   - 守れるカードが無いとき：上の説明に「守れるカードがありません。『受ける』を押してください」、守りの選択の欄に「手札に守りのカード（防御・回避）がありません」。守りのカードを使ったあとでほかに使えるカードが無いときは「ほかに使える守りのカードはありません。『守備を終える』を押してください」
   - 相手の番の始め：相手が直前に使ったカードを薄く（AB のまま。まだ1枚も使っていないときは点線の枠）
   - 相手の番が終わったら、今までどおり自分の側へ 0.3 秒で戻る
