## B. どこで手に入るか（仮）

- ガチャの販売機に「道具のパック（仮）」（シリーズ ID `tools`）。最初から並ぶ。中身はサポート11種類・レアの枠は思い出の箱・熱気・モンスターカードは入らない。値段・確率・枚数はほかのシリーズと同じ。パックの絵は封をしたパック
- 提供割合の窓に「道具のパック（仮）：モンスターカードは入りません」の1行を足した
- **古い PACKS（第1〜3弾・仮）は、今は買える所が無い**（ショップ・ガチャのどちらからも開けない）。残っているのは、大会の賞品の「パックが買えるようになった」の文（`tournamentScreen.ts`）と、QA の「全部のパックを開放」ボタンだけ。中身の sup-1〜6 は ID が同じなので新しいカードになる

## C. 最初の箱・CPU のデッキ・おまかせ

- 最初の箱：`src/data/official/booster_contents_20261030.json`（前の版 `booster_contents_20261029.json` は残した）。技48枚＋指示書の8枚（各1枚足す）＋旅の手帳2・投石2＝60枚
- CPU のデッキ（`src/game/deck/deck.ts`）：`NPC_SUPPORTS` を旅の手帳2・投石2 にした（buildAutoDeck・組み方ごとのデッキ・buildAceDeck）。回復・場のカードは入れない。残りはそのデッキのモンスターの技で埋める
  - 技が足りずに埋めきれないときだけ、ほかのすぐ効くサポート（旅の手帳・投石・風まかせ・霧の香・声援・思い出の箱）で埋める（`NPC_FILL_SUPPORTS`）
- おまかせ（`buildDeckFromCollection`）：旅の手帳・投石を持っていれば2枚ずつまで → 適合技（強い攻撃〔ダメージの大きい順〕と守りを優先、3枚ずつ）→ 技が足りないときだけほかのサポート
