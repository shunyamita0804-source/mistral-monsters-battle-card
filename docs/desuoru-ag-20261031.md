  - エンジン：`useCard` の `choice`（思い出の箱・風まかせと同じ入れ物）に相手の手札の uid。指定が無いときは CPU と同じ選び方（`defaultDiscardChoice`）。捨てたカードは `state.crowEye`（画面のふきだし用）と記録の帯
  - 画面（プレイヤー）：「使う」→ 相手の手札を表で並べた窓（不思議な嗅覚と同じ形）→ 1枚タップ（光る）→「これを捨てさせる」。やめるボタンは無く、窓の外を押しても閉じない
  - 画面（CPU）：プレイヤーの手札は見せない。記録の帯と、相手のふきだし「カラスのめ：「△△」を捨てさせた」
  - CPU（`ai.ts` の `chooseCrowEye`・`pickDiscardChoice`）：その手番に倒せる攻撃が無く、相手の手札が3枚以上のとき（攻撃より先に考える）。A・B は ①倒せる攻撃 → ②いちばん強い攻撃 → ③条件の無い回避 → ④防御、C はランダム
