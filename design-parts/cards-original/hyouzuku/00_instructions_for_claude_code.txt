■ 3. 氷の洞窟の切り札をカルシェルからヒョウズクへ
- イヴァン（enc-ice-boss）：monsters を **[MYU, mon-hyouzuku, KAL]**（真ん中がヒョウズク）、ace を mon-hyouzuku。ノビトンは外す（まきつく＋凍らせるで同じモンスターを止め続ける組み合わせになるため）
- dungeon-04 の firstClearCards：初回クリアは最奥の祭壇でヒョウズクのモンスターカード1枚。2回目から：ヒョウズクの技カード1枚（trumpReward）。宝箱の技カードもヒョウズクの技（風の渓谷と同じ形）
- イヴァンに初めて勝った記録 IVAN_BEATEN_FLAG = 'ivan-beaten'（bossFlag）
- **前に氷の洞窟をクリアしていたセーブ**（カルシェルを受け取った）：水の神殿のセレフィーンと同じく altarOwedFlag で、次に祭壇へ行ったらヒョウズクを受け取れるように（受け取ったカルシェルはそのまま）
- 氷の洞窟のバトラー・見えない番人の編成は今のまま

■ 5. 試遊（npm run playtest:bosses と同じしかた。1000回で決め、200回でも確かめる）
- イヴァンの lifeScale：**V で直す前のイヴァンの勝つ割合（1000回で 21.2％）から ±3 ポイント**に入るように決める
- 次の数も出す（イヴァン戦・最初の手持ち3箱）
  1. 凍らせる（5・9）で、プレイヤーのモンスターが動けなかった手番の割合（全部の手番のうち）
  2. 同じモンスターが続けて動けなかった回数の最大と平均（凍らせ続けが起きていないか）
  3. **決着の理由の割合：倒して勝った／山札切れで勝った（負けた）**。V の報告に「最初の手持ちではボスの山札が切れて勝つことが多い」とあったので、**ボス8人全員**について出す
- ヒョウズクそのものの強さ：ジオルのとき（docs の試遊）と同じしかたで、ほかのモンスターと比べた勝つ割合（内部ランク B の下〜真ん中くらいのつもり）
