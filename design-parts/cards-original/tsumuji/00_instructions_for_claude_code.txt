■ 1. 風の渓谷（ダンジョン）
- ID は今の続き（dungeon-08 など）。名前「風の渓谷」（英語 Wind Valley）。説明：崖とつり橋の渓谷。強い風が吹き、乗ると押し流される。最奥のボスを倒すとクリア
- **D ランクで開く**（水の神殿と同じ）。階4・強さは水の神殿と同じ段（floorLife 0.8〜1.1・viewRadius 1・負けられる回数 3）。ダンジョンを選ぶ所では水の神殿の次に並べる
- 絵：氷の洞窟と同じ作り（床・壁・階段・飾り・ボスの印・ボス戦の背景・入るときの絵と題字・重ねる絵）
- **仕掛け：強い風のマス（gimmick 'wind'・ユーザー決定）**
  - 決まった向き（上下左右）の風のマス。乗ると、風の向きに2マス押し流される（途中に壁・人・物・宝箱・階段があれば、その手前で止まる）
  - 押し流された先がまた風のマスなら、そのマスの風でもう一度流される（ただし同じ階でぐるぐる回らないよう、作るときに輪にならない置き方にする）
  - 風のマスは床に風の線（向きが分かる流れる線・コードで描いてよい。新しい絵は要らない）。乗る前から見えること
  - 1階に4〜8か所。階段・宝箱・人の上には置かない。**押し流されても、階段とボスの間へは必ず行ける**（行けなくなる置き方をしない。テストで確かめる）
  - 押し流される間は、すべる床（氷）と同じように少しずつ動かして見せる。風の音があれば鳴らす（なければ今の効果音でよい）
- 曲：bgm_dungeon_wind.mp3（ダンジョンの中・ボスの間の前まで。ボス戦はほかのダンジョンと同じボスの曲）

■ 2. 人（守り手ゼフィラ・バトラーのニコ）
- **ゼフィラ（Zephyra）**：風の渓谷の守り手＝ボス。肩書き「渓谷の守り手・一族でいちばん若い」（英語は仮訳）。性格：身軽でおしゃべり、明るい若い女性。つり橋を軽々渡る
  - ボスの間に入ったとき・対戦の前後に、顔と短いせりふ（今の守り手と同じ見せ方）。せりふは Claude Code が作ってよい（短く、明るく、よくしゃべる）
  - **勝ったあとのせりふに1つだけ**、口をすべらせる一言を入れる：「ほかの聖地のみんなにも……あっ、今のなし！」のような、守り手の一族がほかにもいると分かる言葉（物語の伏線。くわしいことは言わない）
  - ボスの編成：真ん中がツムジ（mon-tsumuji）。左右はソラモ・ガウル（今のモンスターで。ちがう組み合わせがよければ理由を報告）。強さ（lifeScale）は水の神殿のルシアと同じ 1.2 から始め、フルーネのときと同じ試遊のしかたで勝つ割合を出して報告（ルシアと同じくらいなら 1.2 のまま）
  - 立ち姿 stand_guardian_wind_zephyra は、今の守り手7人と同じく保管（地図はボスのしるしのまま）
- **ニコ（Niko）**：風の渓谷のバトラー。肩書き「つり橋の番」（英語 Bridge Keeper・仮訳）。性格：人なつこく、面倒見のいい青年。守り手の一族ではない
  - 風の渓谷のバトラーに入れる（ほかの新しいダンジョンと同じく「その人＋今の3人のうち1人」の決まりでよい）。地図の上の小さな姿は stand_battler_wind（src/ui/components/dungeonPeopleArt.ts の BATTLER_STANDS に足す）
  - せりふは短く（例：風に気をつけて、など）
- 名刺図鑑：2人を今の最後の番号の続きに（守り手はゼフィラ、バトラーはニコ）。勝つと名刺に記録

■ 4. 新しい決まり（docs/battle-rules.md に「ツムジの効果の扱い」として書く）
1. **02 Wひっかき（ちから・マナ1・ダメージ1）**：今の決まり「モンスター1体は1ターンに技1回」（rules.ts の actionsPerMonsterPerTurn）の、ただ1つの例外
   - ツムジが Wひっかき を使ったあと、同じターンに、手札のもう1枚の Wひっかき を続けて使える（2枚目もマナ1を払う。相手は選び直してよい）
   - 続けて使えるのは **Wひっかき → Wひっかき の1回だけ**（1ターンに Wひっかき は最大2回。3枚目は使えない）。Wひっかき のあとにほかの技は使えない（今の決まりどおり）
   - 2枚目を使うかどうかはプレイヤーが選ぶ（使わずにターンを進めてよい）。手札にもう1枚ないとき・マナが足りないときは、今の決まりどおり
   - 相手（CPU）も同じ決まりで使う
2. **08 かぜのり（特殊・マナ0）**：次の自分のターンの間、ツムジの攻撃技（ちから技・かしこさ技）の消費マナを1減らす（0より下にはならない）
   - 重ねられない（かぜのり を2回使っても −1 のまま）。次の自分のターンが終わったら消える
   - Wひっかき は1枚目も2枚目も −1（マナ0）になる
   - 効いている間は、ツムジに今の状態の印と同じ形の印を出す（手札の技のマナの数字も −1 にして見せられるなら見せる）
   - プカリムのおいかぜ（味方の攻撃＋1）とは別の技（名前を変えたのはこのため）
3. **04 つむじかぜ**：今の undodgeable（回避されない）と同じ
4. **14 かぜよみ**：ちから技・かしこさ技を、消費マナに関係なく回避（今の「回避」の決まりのうち、マナの条件だけ外したもの。ほかのモンスターに同じものがあれば同じ作り）
5. 11〜13 の守り：今の仕組みのまま

■ 5. 相手の CPU（今の思考に足す）
- Wひっかき：手札に2枚あり、マナが2以上あるときは2回続けて使う。1枚だけのときは、ふつうの1マナの攻撃と同じ考え方
- かぜのり：その手番に相手を倒せる攻撃が無く、手札にツムジの攻撃技（マナ1以上）があるとき。かぜのり が効いている間は、マナが減った分で使える大きい攻撃を優先
- つむじかぜ：相手が回避技を持っていそうなとき（今の undodgeable の技と同じ考え方）
