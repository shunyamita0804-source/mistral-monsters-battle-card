■ 1. セレフィーンを正式に
- ID：mon-serephine・skl-serephine-01〜14（docs/card-data-policy.md）。ふつうの一覧（MONSTERS・SKILLS）に入れる。図鑑の番号はフルーネのあと（No.136〜150。cardNumbers.ts）
- LIFE 6。内部ランク C（画面に出さない）。色：月の青紫 #8FA6E8。モンスターカードの枠・技カードの枠の色の表に足す。ほかの枠は変えない
- 英語は仮訳（名前は Serephine）
- カードに書く短い文（src/data/skillCardText.ts。JSON の文は変えない。今の決まりの言い方にそろえる）
  | 技 | 文 |
  | 05 なみ打ち・07 アクアニードル | 回避されない（今の「回避されない」の技と同じ出し方） |
  | 10 みちしお | 山札の上から1枚をマナにする |
  | 11 ミストヴェール | ちから技・かしこさ技に効く |
  | 12 すいっとよける | ちから技を回避 |
  | 13 ゆらりとかわす | かしこさ技を回避 |
  | 14 ウェーブダンス | マナに関係なく、ちから技・かしこさ技を回避 |
  いちばん大きな字で2行に入るか・語の途中で改行しないか（BudouX）を確かめる
- 技の絵の横の位置（src/data/skillArtPosition.ts）：14枚を大きなカード・手札で見て、顔・見せ場が切れるものだけ x を決める。進行の見立てでは、どれも真ん中（50）でよいはず

■ 2. 効果の扱い（新しい仕組みは作らない。docs/battle-rules.md に「セレフィーン」として短く書く）
1. 05 なみ打ち・07 アクアニードル：今の「回避されない」と同じ（防御はできる）
2. 10 みちしお（特殊・マナ0）：山札のいちばん上の1枚を、手札に入れずにそのままマナにする（今の「手札があふれたときに山札の上をマナにする」と同じ仕組み）。山札が0枚なら何も起きない（使えない＝灰色）。使った手番はセレフィーンは攻撃しない（特殊技を使った扱い）
3. 11 ミストヴェール：ちから技・かしこさ技のダメージを2軽減（プカリムのくうきのクッションと同じ）
4. 12：ちから技だけ回避／13：**かしこさ技だけ回避**（今の正式モンスターで初めて。ちから技だけの回避の逆。仕組みが無ければ同じ形で足す）／14：マナに関係なく両方回避（星影ステップと同じ）

■ 3. 相手の CPU
- みちしお：その手番に攻撃で相手を倒せず、次の手番にマナが足りなくて大きい技（ルナタイド・オーシャンウェーブ）を使えないとき。山札が残り少ないときは使わない
- ほかは今の思考のまま（回避されない攻撃は、相手が回避のカードを持っていそうなときに優先 など、今ある考え方があれば使う）

■ 4. 水の神殿のボス・入手の流れ（フルーネとセラと同じ形）
- ルシアのデッキ：**カルシェル・セレフィーン（mon-serephine）・ミュロル**（ソラモを外す。ユーザー決定）。lifeScale は今の 1.2 のまま
- 初回クリア：最奥の祭壇でセレフィーンのモンスターカード1枚（今の受け取り方のまま。今はミュロルを渡しているので、セレフィーンに替える）
- 2回目から：セレフィーンの技カード1枚（14技からランダム。trumpReward）。宝箱の技カードもセレフィーンの技
- 初めて勝った記録：LUCIA_BEATEN_FLAG = 'lucia-beaten'（SERA_BEATEN_FLAG と同じ形）。すでに水の神殿をクリアしているセーブにも付ける（クリアの記録から）。そのセーブがセレフィーンのモンスターカードを持っていなければ、次にルシアに勝ったとき祭壇でセレフィーンを受け取れるようにする
- 水の神殿のバトラー・見えない番人のチームは今のまま
- セーブの version を変える必要があれば1つ上げる
