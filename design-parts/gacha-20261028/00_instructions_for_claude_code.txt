ミストラルモンスターズ バトルカード
Claude Code への指示書：カードショップのガチャを作り直す（2026-10-28）

■ 目的
カードショップの販売機（ガチャ）を、ユーザーと進行チャットがお試しページで決めた形に作り直す。ゲームの中心になる場面なので、手ざわりと演出を最優先にする。
お試しページの HTML を prototype/gacha_prototype_reference.html に入れた（動き・順番・時間の見本。絵は仮で、パスは動かない）。画面写真は prototype/01〜04。

■ 添付
- art/：正式な絵 12枚（ユーザーと進行チャットで検品・承認済み。原本は無改変で design-parts/gacha-20261028/ に保管）
  - pack_{soramo,gauul,lazuck,nobiton,myurol,kalshell}.png（600×1080）：シリーズのパック
  - knob_base.png・knob_dial.png（900×1300。今の機械の部品と同じ原点）：つまみの台と回る部分。回る中心は (650,1000)
  - outlet_zoom_back.png・outlet_zoom_front.png（1080×1080）：取り出し口に寄ったときの絵（奥と床／手前のふち）
  - select_bg.png（1170×2532・不透明）：シリーズを選ぶ画面の背景
  - open_burst.png（1080×1080）：開けたときの光
- prototype/：お試しページの HTML と画面写真、絵の確認画像

■ 流れ（今の「パックを選ぶ → ハンドル → 開封」を置き換える）
1. 販売機を調べる → **シリーズを選ぶ画面**（select_bg）
   - 6つのパックを3列×2段。パックの下に「○○のパック」と「○ / 15 そろった」
   - 1回タップで光って少し浮く、同じパックをもう1回で決定（主人公選び・ブースター選びと同じ。連打で決まらないように）
   - 決めたら値段の確認（今の「はい／いいえ」の窓）→ 払って機械の画面へ
2. **機械の画面**
   - 上に、そのシリーズのラインナップ（モンスター1＋技14＝15枠）。手に入れたカードは絵が見え、まだのものは「？」。下に「○ / 15 そろった」
   - 上に「○○のパック」と「パックを選び直す」（選び直しは払う前だけ。払ったあとは出さない）
   - 機械のガラスの中のパック・出てくるパックは、選んだシリーズの絵
   - **ハンドルをやめて、つまみ**：machine_seat・handle_disc・handle_crank の代わりに knob_base（動かない）と knob_dial（回る）。
     指で時計まわりに1周（360°）。反対まわりでは進まない（今のハンドルの角度の計算を使ってよい）。18°ごとに「カチッ」（今の sound.ratchet）
   - 「自動でまわす」ボタンは今のまま残す
3. **まわし終えたら**：機械が小さく揺れる（ガシャン：今の chestUnlock の音）→ 取り出し口が開く →
   **画面が取り出し口へ寄る**（0.6秒くらい）。寄りきったら outlet_zoom_back / outlet_zoom_front の細かい絵に切り替える（機械の絵の拡大だとぼやけるため）
   - パックは寝た形（奥へ倒した遠近）で、奥から手前へすべり出て、手前のふち（outlet_zoom_front）からはみ出して止まり、ふわっと光る。音は card_slide
   - 「タップして取り出す」→ タップで開ける画面へ
4. **開ける**：選んだシリーズのパックが大きく出る。上から約17％の所を指で横になぞると破れる（なぞった所に光の線。60％なぞったら破れる）。
   破れた瞬間に open_burst と pack_open の音
5. **めくる**：5枚が重なって出る。いちばん上が表に返る。**タップ、または好きな方向へスライド**すると、そのカードがスライドした向きへ飛んでいき（タップなら左上へ）、
   次のカードが表に返る。最後の1枚の前は少し間をおいて「最後の1枚…！」
   - カードは**ゲームの今のカードの見た目**（技カード＝マナ・ダメージなどが書かれた手札のカード、モンスター＝バトル用カード）で出す。お試しの「絵だけ」ではない
   - 飛ばしたカードは下に小さく並べ、初めて手に入れたカードには「NEW」
   - 強い技（レア枠）：カードが光の筋で光り、card_reveal の音。**文字は出さない**
   - モンスターカード：画面が白く光り、open_burst、reward の音、「モンスターカード！」
   - 全部めくったら「もう1回（同じシリーズ。値段の確認あり）」と「もどる」

■ 中身と確率（すべて economy.ts など1か所にまとめ、あとで数字を変えやすくする）
- 1シリーズ＝1モンスター。今は6シリーズ。**すべて最初から選べる**（仮）。値段は**どれも 150G**
- 1回5枚。中身は無限（のこり数なし）。**天井なし**
- **カードにレアリティの表示は出さない**（C・U・R などの札も、提供割合の表の「レア」の文字も出さない）。中の確率だけ「ノーマル枠」と「レア枠」に分ける
- 1枚ごとの出やすさ：**ノーマルの技1種＝重み4、レアの技1種＝重み1**（レアはノーマルの4分の1）
- **モンスターカード：1パックに5％**（当たったら5枚のうち1枚がモンスターカードに替わる）
- 開ける順番：ノーマル → レア → モンスター（強いものほど最後）
- 同じカードの4枚目から：**そのまま持つ**（今のゲームと同じ。お金にかえない）
- レア枠（ユーザー決定。技の名前で指定。ID は今のデータから引く。推測で作らない）
  | モンスター | レア枠 |
  | --- | --- |
  | ソラモ | ソラモビーム・星影ステップ |
  | ガウル | 聖なる炎・炎の壁・高速飛行 |
  | ラズック | とびかかり・トリックショット・シャドウバースト・フェイントステップ |
  | ノビトン | まきつく・ダウナーミスト・のびのびガード・必死によける |
  | ミュロル | スリップガード |
  | カルシェル | てっぺきシェル |
  ほかの技はすべてノーマル枠。シリーズの中身はそのモンスターの正式14技＋モンスターカード
- 提供割合の画面（今の gacha-rates）は、「モンスターカード：1パックに5％」と「技カードは、技によって出やすさがちがいます」の2行にする（技ごとの％やレアの文字は出さない）

■ 片づけ
- 今の仮パック（pack-01〜03・仮モンスターA〜I）は販売機から外す（データが他で使われていれば消さずに残す）
- 管理局で受け取るブースター（3箱）とカウンターの棚は、このガチャとは別。今回はさわらない
- 新しいモンスター（ジオル・フルーネなど）が来たら、パックの絵1枚とレア枠の一覧を足すだけでシリーズが増える作りにする

■ 確認と報告
- テスト：確率（1万回でモンスター約5％・レア1種がノーマル1種の約4分の1）、順番、値段、払う前だけ選び直せる、連打で二重に払わない
- 画面写真（390×844）：シリーズを選ぶ画面（1回目の光）、機械の画面（つまみ）、取り出し口に寄ったところ、パックを破るところ、技カードとモンスターカードが出たところ、全部めくったところ
- iPhone で音が鳴るか（今の音の仕組みで）
- 終わったら main に取り込み、公開して、公開ページでも確かめる。記録を docs/ に残す
