ミスモンBC｜名前の入力・取得カード画面・ボタンの効果音・手札の上限（2026-10-28 進行チャット）

PS版（モンスターファームバトルカード）の仕組みの考え方だけを取り入れる（絵・画面の見た目はオリジナル）。
4つとも、ユーザーが決めたこと。終わったら main に取り込んで公開し、画面写真（390×844 と 375×667）で報告してください。

■ 入っているもの
- se/ui_tap・ui_decide・ui_cancel・ui_disabled（.wav が原本・.mp3 はゲーム用に変換したもの。進行が合成した音なので使ってよい）
- ref/ui_se_samples_all.m4a：聞き比べ用（①〜⑥。ゲームには入れない）

==================================================
1. 名前を決める（主人公を選んだすぐあと）
==================================================
- 今は名前を決める所がない。主人公（男・女）を選んだすぐあと（newGameScreen で決めたあと、導入が始まる前）に名前を決める画面を出す
- 形：スマホのキーボードで入れる、今のスマホゲーム風の形（50音の文字盤は作らない）
  - ゲームの絵の窓の中に、案内役ミレイユの顔と「あなたの名前を教えてね。」、その下に入力欄と「決定」のボタン
  - 入力欄をタップするとスマホのキーボードが出る。漢字・ひらがな・カタカナ・英数字が使える
  - **キーボードが出ても、入力欄と決定ボタンが隠れないように窓を上へずらす**（iPhone の Safari。visualViewport などで）
- 決まり
  - **最大8文字**（見た目の1文字＝1文字。漢字の変換中の文字で切らない）
  - 前後の空白は消す。絵文字と、一部の記号（< > / \ など表示やセーブを壊すおそれのあるもの）は入らない
  - 1文字も入っていないときは「決定」を押せない（灰色。押すと ui_disabled の音）
  - 「決定」→「○○ でいい？」「はい／いいえ」で確かめる。はい＝決まり（ui_decide）、いいえ＝入力に戻る（ui_cancel）
- セーブ：player.name に入れる（SAVE_VERSION を上げ、変換を足す。前のセーブは name なし）
  - 前のセーブで遊んでいる人は、次に「つづきから」で始めたとき1回だけ、同じ名前の画面を出す（ミレイユの文は同じでよい）
- 名前を出す所：会話で主人公を呼ぶ所・名刺図鑑・対戦の VS・大会の表など、今「あなた」などで代わりにしている所のうち、名前を出すのが自然な所は名前に（どこを変えたか一覧で報告）。
  対戦の画面の「あなた／相手」の札のような、役割を表す所は今のままでよい
- **8文字が切れずに入るか**：「ああああああああ」「ＷＷＷＷＷＷＷＷ」（全角）「WWWWWWWW」で、名前を出す所をそれぞれ画面写真で確かめる。入らない所は文字を小さくする

==================================================
2. 箱を開けたあとの「取得カード」画面
==================================================
- 今は管理局で箱を選ぶと「○○ を受け取った！」の文だけ（introV2.pack.got）。そのあとに「取得カード」の画面を出す
- 中身：もらったカードの一覧（モンスター3体 → 技カード → サポートの順。名前と枚数「×3」など）
  - 一覧の行をタップすると、そのカードを大きく出し、効果も見られる（今のカードの部品をそのまま使う）
  - スマホの縦の画面なので、上に選んだカードを大きく、下に一覧（たくさんあるときは一覧だけスクロール）
  - 最初は1行目（モンスター）を選んだ状態。「閉じる」で次へ
- あとで、ダンジョンの勝ち・宝箱・ガチャの結果でも使えるように、部品として作る（今回つなぐのは箱だけ）

==================================================
3. ボタンの効果音（今のゲームにはボタンの音が無い）
==================================================
- ui_tap（①澄んだ「ピッ」）：ふつうのボタン・メニュー・タブ・一覧の行を押したとき
- ui_decide（④）：決める（決定・はい・買う・出発など、次へ進むボタン）
- ui_cancel（⑤）：戻る・いいえ・閉じる
- ui_disabled（⑥）：押せない（灰色の）ボタンを押したとき
- 音の大きさは設定の効果音の音量に従う。ほかの効果音より少し小さめ（耳につかないように）
- **すでに音が鳴るボタン（ガチャのつまみ・扉・カードを使う など）では二重に鳴らさない**
- 対戦中のカードの操作（手札をタップ・持ち上げる・使う）には付けない（カードの音があるため）
- 今の効果音と同じしくみで鳴らす（iPhone で遅れない・ほかの音を止めない）

==================================================
4. 手札は最大9枚
==================================================
- 手札は最大9枚（ユーザー決定）
- カードを引く効果（ドロー・考える など）で9枚を超える分は、引かずに山札の上からそのままマナにする
  （今の「手札5枚のときのドローは、山札の上をマナにする」と同じ考え。捨てる画面は作らない）
- ターンのはじめの「5枚まで引く」は今のまま
- 山札が足りないときの決まり（負け）は今のまま。相手の CPU も同じ決まり
- 対戦の記録の文：「手札がいっぱいなので、山札の上をマナにした」などが分かるように
- テストを足す（9枚のとき引く効果で引かない・その分マナになる・9枚未満なら9枚まで引いて残りをマナ）
