## 霧のマスを作るときの覚え書き

- 絵は濃さがどこも同じなので、霧のかたまりのふちはぼかして溶かす（四角い境目を出さない）
- 霧をゆっくり流す
- 霧の渦の絵を薄く重ねて、濃淡のむらを出す
