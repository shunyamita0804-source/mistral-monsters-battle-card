## 【1】フギン（mon-huginn）

### どんな子か
- **ネブラシア地方（頭の良い地方）の王者ザイレンの切り札**。双頭のカラスの聖獣（北欧神話の「思考のカラス」がモデル）
- 戦い方：**回避の技を山札から探して手札にそろえ、相手の大技をかわし続ける。安い攻撃でけずり、すいりのいちげきで仕留める**
- LIFE **6**・内部ランク **B**（B の上）・居場所 **空中**（MONSTER_HABITAT に 'air'）・防御0・回避2
- 枠の色 **#1F5C58**（深い暗めの青緑。カードの絵の枠は実測 #135853 前後）。ハクランの青緑より暗く緑寄り
- 名前：日本語「フギン」・英語「Huginn」（n が2つ。ユーザー決定）。説明の文は仮でよい（例「ふたつの頭で先を読む黒いカラス。羽の先は結晶でできている。」と英語の仮訳）
- ザイレンのデッキの相棒（マナを吸う聖獣）は別に作っている途中。今回は入れない

**今ある作りで作れるもの**
- 05＝attack の halfOnEvade（切り捨て。回避されたら 2）。09＝unblockable。11＝dodge('all')
- 08＝attack の manaDrain: 1（ノビトンのくしゃみ・フルーネのかふんと同じ。0 より下にしない）
- 12＝「マナ2以上の〜を回避する」の形（BK でそろえた文）。今ある作りがあればそれを使う。無ければ作る（要確認で報告）

**新しいもの（3つ）**
1. **06 よみのまなざし**：攻撃が回避されなかったとき、当たった相手に「封じ」（seal＝次の攻撃を行えない。ソラモのすなかけと同じ印と決まり）を付ける。攻撃と封じを1枚で行う形は初めて
2. **07 ちえのささやき**：
   - 自分の山札から**回避（避）の技カード**を1枚選んで手札に加え、山札をシャッフルする。フギンの技に限らず、自分の山札にある回避の技ならどれでもよい
   - 山札に回避の技カードが無ければ、かわりに山札から1枚引く。山札が0枚なら何もしない（山札切れの扱いはいつもどおり）
   - プレイヤーは候補を見て選ぶ。CPU は、使えるマナで出せる回避を優先し、同じなら さきよみ → かぜよみ の順に選ぶ
3. **10 はねやすめ**：
   - 使ったフギンに印を付ける。このあとフギンが**回避の技を1回使うとき、その技のマナを 0 にする**。使ったら印は消える
   - 期限なし（使うまで残る）。重ねない（印が付いているあいだにもう一度使っても 1 回分のまま）
   - フギンが倒れたら消える。ほかのモンスターの回避には効かない
   - 印は「ほっぺにためる」とは別の見た目が望ましい。手間なら同じでもよい（要確認で報告）

**CPU（目安）**
- 07：手札に回避が無いときに使う
- 10：手札に かぜよみ があって、マナが2に足りないとき、または次の相手の手番に大技が来そうなときに使う

**文**
- BK でそろえた決まりの形（防御・回避）
- 08 の文は「回避されなければ、相手のマナを1減らす」（くしゃみと同じ書き方があれば、それに合わせる）
