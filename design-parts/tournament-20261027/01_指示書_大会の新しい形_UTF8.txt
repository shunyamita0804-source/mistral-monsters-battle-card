# ミストラルBC 大会の新しい形（総当たり・トーナメント・常連）（指示書）

## 目的
公式ランク戦を、本編（ミストラルモンスターズ）にならって作り直す。
- E・Dランク：4人の総当たり（本編と同じ、顔の並んだ対戦表）
- C〜Sランク：8人のトーナメント（1回戦・準決勝・決勝の3試合）
- 性格のある「常連」が、ランクごとに出てくる

既存のプロジェクト構成・CLAUDE.md の方針に従うこと。人物の名前・顔は、別の指示書「名刺図鑑とカード図鑑」の人物データを使う。

## 範囲
- 大会の進め方・対戦表・トーナメント表・順位・常連の出場・相手の戦い方
- C〜Sランクの大会を新しく作る（いまは E・D だけ）
- 数値（賞金・相手の強さ・デッキ）はすべて**仮**。1か所（`src/data/tournaments.ts` など）にまとめる
- 絵はデザイン担当に依頼中（一般の出場者8人の顔・総当たり表の部品・トーナメント表の部品）。届くまでは仮の見た目でよい。顔が無い人は仮の人影でよい
- 大会の背景は、いまの大会の絵を使う（E は今の背景、D は D の背景、C〜S は当面 D と同じでよい）

## 1. E・Dランク：4人の総当たり
- 出場：主人公＋相手3人。1人3試合
  - E：ノエル・ヴィクトル・シエナ
  - D：ダリオ・イザベラ・ゴードン
- 進め方：1回の「対戦する」で主人公が1試合。同じ回のほかの2人の試合は、自動で結果を出す
  - 結果の出し方：既存の自動対戦で決める。時間がかかるなら、強さ（lifeScale・デッキ）から確率で決めてよい（どちらにしたか報告）
- 順位：①勝ち数 → ②勝った試合で残った自分のモンスターの数の合計 → ③与えたダメージの合計 → ④抽選。同率1位は作らない
- 1位で優勝。2位以下は優勝ではない（参加賞だけ）
- **対戦表**：本編の総当たり表の4人版（ユーザー添付の画面のとおり）
  - 左の列と上の行に、顔と名前（主人公は男女の顔）
  - 自分どうしのマスは斜線。終わった試合は勝ち・負けの印
  - 次の相手のマスを光る枠で囲む。自分の行はうすい帯
  - 下に「対戦する」。3試合が終わったら順位表 → 優勝なら今までの優勝の場面
- 相手との対戦の前の流れ（VS・先攻後攻・ひと言）は、いまと同じ

## 2. C〜Sランク：8人のトーナメント
- 出場：主人公＋7人。1回戦（4試合）→ 準決勝（2試合）→ 決勝。3連勝で優勝
- 主人公が負けたら、その大会はそこで終わり（残りの試合は自動で結果だけ出して表を埋める）
- ほかの人どうしの試合は、総当たりと同じやり方で自動で結果を出す
- **トーナメント表**：縦長の画面に、8人を左右4人ずつ。真ん中の上に優勝杯
  - 出場者の札（顔＋名前）。勝ち残り・敗退で見た目を変える
  - 勝ち上がった線が光る。いま戦う対戦に印
  - 下に「対戦する」

### 出場者（常連＋一般）
| ランク | 常連 | 一般の出場者 |
| --- | --- | --- |
| C | シエナ・ドルフ・レナード | C・B組から4人 |
| B | ドルフ・レナード・グレタ・ユリウス | C・B組から3人 |
| A | レナード・グレタ・ユリウス・カミラ | A・S組から3人 |
| S | ユリウス・カミラ・アルヴィン | A・S組から4人 |

- 一般の出場者（名刺図鑑には載せない。名前と顔だけ）
  - C・B組：トビアス（Tobias）・マリー（Marie）・ジャン（Jean）・ヘレナ（Helena）
  - A・S組：クロード（Claude）・ベアトリス（Beatrice）・ザラ（Zara）・ウォルター（Walter）
- 組み合わせ：常連は毎回出る。一般は組の中から必要な人数をランダム
- **C ランクだけ**：シエナを主人公と反対の山に置き、シエナは決勝まで必ず勝ち上がる（決勝の相手はシエナ）
- **S ランクだけ**：アルヴィンを主人公と反対の山に置き、決勝まで必ず勝ち上がる（王者が決勝で待つ）

### Cランク大会のあと
- Cランク大会を終えたら（優勝しても負けても）、「シエナがいなくなった」の記録を立てる
- この記録は、あとで作るイベントダンジョン「霧の廃坑」が出てくる条件に使う。**今回はダンジョン・会話は作らない**（記録だけ）

## 3. 常連の戦い方（デッキと考え方）
常連には性格に合わせたデッキと、相手の考え方の癖を付ける。デッキは今ある正式カード（ソラモ・ミュロル・ガウル・ラズック・ノビトン・カルシェル）から、仮で組んでよい。

| 常連 | デッキ | 考え方 |
| --- | --- | --- |
| シエナ | 偏りのない、まっすぐな構成 | ふつう |
| ドルフ | 必要マナの多い強い攻撃ばかり。守りはほぼ入れない | いつも攻撃を優先 |
| レナード | ちょうはつ・すなかけなど妨害が中心 | 妨害を先に使う |
| グレタ | 防御・回避が多い | 守りを優先。相手の山札切れを待つ |
| ユリウス | 華やかな大技 | 大技を優先 |
| カミラ | 強くてバランスのよい構成 | 相手の弱いモンスターを先に狙う |
| アルヴィン | いちばん強い構成 | カミラと同じ考え方で、強さはいちばん上 |

- 一般の出場者は、ランクに合った強さのふつうの構成でよい
- 強さの目安（lifeScale など）は仮。C＜B＜A＜S の順に強く

## 4. 常連の見せ方
- 勝ち抜き表で、常連は名前の上に二つ名を小さく出す
- 常連の通算の勝率を、札を押したときに出す（例：「勝率91%」）。値は仮の固定値でよい（カミラ 91%・アルヴィン 100% など）
- ユリウスの試合だけ、観客の声を大きくする（音があれば。無ければ報告）

## 5. 報酬（仮）
- E・D：いまの値のまま
- C〜S の初優勝：賞金 C 500G・B 600G・A 800G・S 1000G、ランクアップ C→B→A→S。2回目以降の優勝は初回の半分。参加賞 C 40G・B 50G・A 60G・S 80G
- パックの解放・カードの景品は、C 以上では付けない（決まっていないため）

## セーブ
- 大会の途中の状態（総当たりの結果・トーナメントの組み合わせと勝ち上がり）を中断セーブに入れる。途中でアプリを閉じても、次の試合から続けられる（試合の途中なら、その試合はやり直し）
- C〜S の初優勝の記録、「シエナがいなくなった」の記録。形式を変えるので `SAVE_VERSION` と `MIGRATIONS`

## テスト
- 総当たりの順位の決め方（同率の並べ方）
- トーナメントの勝ち上がり・負けたら終わり
- C でシエナ、S でアルヴィンが決勝に来ること
- 常連のランクごとの出場、一般の出場者の選び方
- 中断と再開

## 進め方
- この指示書の仮の値のほかは、価格・報酬・イベント内容を推測で決めない
- 未決事項は作業を止めず、最後にまとめて報告すること
