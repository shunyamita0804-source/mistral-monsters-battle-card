# 街・部屋の部品の原本（2026-10-22〜）

`tools/design/seimon_world_build.py` で街・部屋の絵を作り直すときに使う部品。**ゲームには直接入らない**（ビルドの対象外。ゲームが読むのは作り直した `assets/images/maps/`）。
以前は原本をリポジトリに入れておらず、作り直すたびにユーザーに再送してもらっていた。2026-10-22 ユーザー指示で、届いた原本をここに保管する。

使い方：`python3 tools/design/seimon_world_build.py design-parts/seimon-world 確認画像の出力先`（部品がそろってから）

受け取ったファイルは**そのまま**（名前だけ、`docs/design/seimon-town/05_補助資料/02_納品ファイル名一覧` の保存名に付け直し）。

## 2026-10-26：街の色の調子（ユーザー指示「弱めで全体にかけて」）

街が古びて見えるので、`tools/design/seimon_world_build.py` で街を組み立てるときに、街の部品（建物・地面・小物・草花・噴水）へ
明るさ×1.08・あざやかさ×1.18・コントラスト×1.04・少し暖かく、をかける（`TOWN_TONE`）。**ここの原本は変えていない**（組み立てるときに写しへかける）。
カードショップ・大会会場（ユーザーが調子を変えて描いた新しい絵）と、部屋の中にはかけない。苔やひびなど絵に描かれたものは消えない。

## 2026-10-26：カードショップを新しい絵に置き換え

ユーザーがチャットで送った絵（1536×1024・透過の WebP。屋根が丸い新しいデザイン）で `town_shop.png` を置き換えた。
絵のまわりに薄い茶色のもや（半透明）が付いていたので、不透明度 220 より薄い所を透明にした（絵そのものは変えていない）。前の絵は git の履歴にある。
前の絵より少し横に広い（となりの研究所とは重ならない）。入口の位置は道と合っている。作り直しで変わったのは街の左の2枚（`town_r1c0`・`town_r2c0`）と名前の札の位置だけ。
