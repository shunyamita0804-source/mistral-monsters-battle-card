## 【1】ノウス（mon-nous）

### どんな子か
- **ネブラシア地方の王者ザイレンの本当の切り札**（フギンは相棒）。水晶のドームの頭を持つ、6本腕の聖獣。マナを吸い、山札を削る
- 戦い方：**かしこさ技で相手のマナを吸って大技を打たせず、ときをすいとるで山札を削って山札切れに追い込む**
- LIFE **7**・内部ランク **B**（B の上）・居場所 **空中**（MONSTER_HABITAT に 'air'）・防御1・回避1
- 枠の色 **#CC6A1F**（深い琥珀）。ガウル・ノビトン・クロシオと見分けられるか、写真で確かめる（近ければ要確認で報告）
- 名前：日本語「ノウス」・英語「Nous」（ユーザー決定）。説明の文は仮でよい（例「星を読む塔に住む聖獣。6本の腕と鼻で、知恵とマナを吸い取る。」と英語の仮訳）。**神様・信仰に触れる言葉は使わない**

**ユーザーの決まり（2026-11-06）：特殊技でマナは減らさない**（回避できないため）。マナを減らすのは、回避できる攻撃（かしこさ技）だけ。

**今ある作りで作れるもの**
- 02・04＝attack の manaDrain: 1／2（ノビトンのくしゃみ・ダウナーミストと同じ。0 より下にしない）
- 08＝redrawHand（ノビトンの 考える と同じ作り）
- 11＝guard(3,'force')、12＝dodge('all')

**新しいもの（3つ）**
1. **06 からっぽのつぼ**：回避されなければ、相手のマナを 0 にする（manaDrain の「全部」版）。印・ログはくしゃみと同じ見せ方でよい
2. **09 ときをすいとる**：相手の山札の上から2枚を捨て札にする。山札が1枚なら1枚、0枚なら何もしない（この技で山札切れの負けにはしない。山札切れの判定はいつもどおり引くとき）。捨てたカードはログに出す
3. **10 ぜんちぜんのう**：自分の山札から好きなカードを1枚選んで手札に加え、山札をシャッフルする。フギンの ちえのささやき（searchEvade）の「回避だけ」をはずした形。山札0枚のときは使えない（ちえのささやきと同じ）。CPU の選び方：使えるマナで撃てる、いちばんダメージの大きい攻撃 → なければ回避 の順（要確認で報告）

**CPU（目安）**
- 06：相手のマナが3以上のときに優先
- 09：相手の山札が少ないほど優先
- 08：手札に使える技が無いとき
