# 指示書 AY2（2026-11-05 進行チャット）：テオの3枚コンボの直し

AY の報告のあと。ブランチ ay2-teo を切る。公開はしない。テストが通ったら main に入れてよい。

## なぜ
AY でテオが α・β・γ を3枚ずつ持ち、マナにもしないようにした結果、手札が詰まってテオが弱くなり（プレイヤーが勝つ 36.9%）、ライフを 1.82 に上げたら **テオ戦の 50.2% が山札切れ**になった。ボスが硬すぎて倒しきれない戦いは楽しくないので直す（ユーザー決定：取っておく札を減らす）。

## 直すこと
1. テオのデッキの α・β・γ を **2枚ずつ**（aceCopies 3 → 2）
2. 取っておくのは **α・β・γ それぞれ1枚まで**。同じ札の2枚目は、ふつうに使ってもマナにしてもよい。1種類しか手札に無いうちは取っておかない（今の「2種類以上で取っておく」のまま）
3. 取っておくあいだも、手札が詰まって使える技が無くなるときは、取っておくのをやめてふつうに使う（使える技が0枚になる手番を作らない）
4. **lifeScale は 1.60 に戻す**。強さが足りなければ、ライフではなくデッキで補う：テオの3体（ノビトン・ギアロス・ガウル）の強い技・レアを入れる、守りのカードの数を見直す など。何を変えたか報告に書く
5. 目標（目安のプレイヤー A・3箱 × 1000回）
   - テオに勝つ割合 13±3%
   - テオ戦の山札切れ **25% 以下**
   - コンボを使った対戦 20% 以上
   - 3つを同時に満たせないときは、山札切れ → 勝つ割合 → コンボ の順に優先し、表を出して止める（ライフを 1.60 より上げない）
