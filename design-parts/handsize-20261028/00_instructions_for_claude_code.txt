Claude Code への指示書：手札のカードの大きさ・マナとダメージの数字（2026-10-28）

※ 「Mistral_CardLook_ClaudeCode_v2_20261028.zip」（カードの見た目3点 v2）が終わってから作業する。
  カードの裏面は今回は変えない（v2 の、金のふちを太くした絵のまま）。新しい裏面はデザイン担当が作っていて、届いたら別に頼む。

■ 1. 手札のカードを少し大きくする（hand_size_options.png の「C」）
- 今：battleScreen.ts の HAND_CARD_W = 80（最小 HAND_CARD_MIN_W = 70）
- 変更：手札のカードの幅を 90 に。枚数が多くても **カードは小さくしない**（今の「HAND_CARD_MIN_W まで縮める」はやめる）。入りきらない分は、今の --hand-overlap の仕組みで重ねる量を増やして全部を1列に入れる
  - 重ね方：右のカードが左のカードの右側に重なる。マナとダメージはカードの左側にあるので、どの枚数でも各カードの左はし（マナの玉とダメージの四角が見える幅。目安でカードの幅の 35% 以上）は隠さない
  - 枚数がさらに多く、左はしすら残せないときは、それ以上重ねてよい（カードはタップで大きく出せるので中身はそこで確かめられる）。ただし1枚ずつ指で選べる幅（約 28px 以上）は残す
  - 選んだカード・触っているカードは今どおり一番手前に出て、全部見えること
- 相手の手札（裏面）も今どおり自分と同じ大きさで、多いときは同じように重ねる
- 縦が足りないときの決まり：390×844 では幅 90。画面の縦が足りず、手札の列・場・ボタンが重なったり切れたりする画面（例：375×667 の iPhone SE）だけ、今の幅 80 に自動で戻す（横に入りきらないことを理由に小さくはしない）。どの画面でも重なり・切れがないこと
- 確かめる枚数：5枚・7枚・10枚

■ 2. マナの玉とダメージの数字を大きくする（1.4倍）
- 手札・大きなカード・ガチャ・図鑑・デッキ編集など、技カードとサポートカードが出る所すべて同じ倍率で
- マナの玉：skillCard.ts の manaOrb で置いている mana_*.png（と数字だけのとき .skill-card__mana--text）を、玉の中心（LAYOUT の orb の位置）はそのままで 1.4倍の大きさに。枠の玉の台より大きくなってよい（台を覆う）
- ダメージ・軽減の数字（cards.css の .skill-card__value-num）：15cqw → 21cqw。手札用の大きさ（.skill-card--hand）は 18cqw → 22cqw。盾のアイコン（.skill-card__value-shield）も 1.4倍
- 短い文字（特殊・回避・サポートの区分、.skill-card__value-word）：今の約1.3倍（6.5→8.5cqw、手札用 7.5→9.5cqw、サポートの4文字は欄に収まる大きさまで）
- 2けたの数字（例：30）が左下の四角からはみ出したり切れたりしないこと。はみ出すときは、その欄の中に収まる大きさまで下げる
- 大きなカード（説明の文が出るとき）で、「ダメージ」などの小さい字（.skill-card__value-sub）が数字と重ならないこと
