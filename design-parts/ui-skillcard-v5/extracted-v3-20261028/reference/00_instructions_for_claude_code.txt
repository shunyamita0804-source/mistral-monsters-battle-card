- やること：
  - 原本は無改変で design-parts/ui-skillcard-v5/extracted-v3-20261028/ に保管（今の extracted も残す）。reference/ の注記・比較画像もそこへ
  - ゲーム用は今と同じ大きさ・同じ位置に。くっきりさせたければ今の2倍で書き出して、CSS で同じ大きさに表示してよい（LAYOUT の位置は変えない）
  - 分類の色の枠・モンスターの色の枠（frame_*_{soramo,gauul,lazuck,myurol,kalshell}）を、すべて新しい枠から作り直す
  - 色を付ける所の型（frame_*_tintmask）は必ず作り直す（窓のまわりで「前は透明、今は枠」になった所がある。今の型のままだと、そこだけ色が付かない）

  - 窓が少し小さくなるので、技カードの絵が窓の下で切れて変に見えないか確かめる（絵の大きさ・位置は変えない）
  - 技カードとサポートカードが出る所すべて（手札・大きなカード・守備のカード・ガチャ・図鑑・デッキ編集・カウンターの箱など）で新しい枠になること
  - 作り直しの手順を1つのコマンド（または npm スクリプト）にまとめて、docs/ に書いておく（今後、枠の絵を同じ名前で差し替えたときにすぐ作り直せるように）

■ 3. 場のモンスターのカードの二重の枠をなくす（v2 と同じ）
- ingame_double_border.jpg のとおり、場のモンスターのカードの外側に、カードの絵の枠とは別の色の線がある（battlePs.css の .battle__monster-icon の border: 2px solid var(--side-color)）。枠が二重に見えて安っぽいので、この線を消す
- 自分か相手かは上下の位置で分かるので、色の線は要らない
- この線で出していた「選んでいる・狙える・攻撃されている」などの印は、線ではなく、カードのまわりがやわらかく光る形（box-shadow や filter: drop-shadow）に変える。光の色で色分けしてよい
