## 正式確定の人物像
強い相手を求めて各地を旅する、真っすぐで負けず嫌いな若いバトラー。強敵に出会うこと自体を喜ぶが、闘志は強く、相手の実力を素直に認める。ドルフのごり押しやゴードンの古参の誇りとは異なり、向上心と挑戦する喜びが個性。
一人称「俺」、相手「アンタ」ではなく会話の自然な「あんた」。語尾「！」を多用しない。発言頻度は中程度。

| 場面 | 正式セリフ |
|---|---|
| 対戦開始 | 強い相手を探してたんだ。あんたの腕、見せてくれ。 |
| 攻撃命中 | よし、手応えありだ。 |
| 攻撃を受ける | ……いい一撃だ。わくわくしてきた。 |
| カイルが防御成功 | そこは読んでたぜ。 |
| 主人公が防御成功 | いい守りだ。簡単には崩せないな。 |
| カイルが回避成功 | 危ねえ、紙一重だった。 |
| 主人公が回避成功 | へえ、よく見切ったな。 |
| 相手のモンスター撃破 | まず一体。まだまだいくぜ。 |
| 相手の残り1体 | あと一体か。最後まで全力でこい。 |
| 自分のモンスターが倒れる | やるな……ますます面白くなってきた。 |
| 自分の残り1体 | 最後の一体か。なら、全部ぶつける。 |
| カイル勝利 | 俺の勝ちだ。いい手合わせだったぜ。 |
| カイル敗北 | 参ったよ。あんたみたいな相手がいるから、旅はやめられない。 |
