## 【0】今の機械の塔（進行が main で確かめた）
- RUN_DUNGEONS の dungeon-06：5階・A・gimmick 'switch'（ゴールの部屋の入口を扉にし、スイッチ1つで開く）・floorLife 1.1〜1.5・敵は C の子（ノビトン・ラズック・カルシェル・ガウル）
- 絵（machine_*）・曲（bgm_dungeon_machine）・バトラーのオットー・守り手のテオ・切り札ギアロスは入っている
- A ランクのダンジョンなのに仕掛けがいちばんやさしく、敵が最初の箱の子ばかり → 直す（ユーザー決定）

## 【1】仕掛け：切り替えの扉（ユーザー決定）
- 階に **赤の扉** と **青の扉** がある。どちらか一方の色だけが開いている（階に入ったときは赤が開き、青が閉じている）
- **スイッチを踏むたびに、開いている色が入れかわる**（赤が開いて青が閉まる ⇔ 青が開いて赤が閉まる）。スイッチは何度でも踏める
- 階の作り方（generate.ts の switch を作り直す）
  - 1・2階：スイッチ1つ。1回切り替えるとゴールの部屋へ行ける
  - 3〜5階：スイッチ2〜3つ・扉は4〜6か所。ゴールまでに2回以上の切り替えが要る（同じスイッチに戻ってもよい）
  - 道の決め方：「いる場所 × 扉の色」で行ける所を調べて、**どの状態からでも必ずゴール（階段・ボス）へ行ける**こと（閉じこめられない）。バトラー・宝箱もどこかの状態で必ず行けること
  - 扉のマスにだれか（主人公・バトラー・宝箱）がいる置き方はしない
- 見た目
  - 扉：今の machine_door_closed／open を赤と青に染めて作る（色だけ。形は同じ）。開いた扉は床と見分けがつく
  - スイッチ：今の色が分かる絵（赤／青。今の machine_switch_off／on を染めて）
  - 画面の上の帯の左（場のアイコンと同じ所）に、**今開いている色**の小さな印（文字なし）
  - ミニマップにも扉の色
  - スイッチを踏んだとき：短い音と、扉が開く／閉まる小さな動き
- セーブ：dungeonRun に今の色を入れる（中断から再開しても同じ）。セーブの version を上げたら理由を書く
- CPU の自動歩行（案内の自動歩行があれば）も扉の色を考える
- 試遊（150シード×5階）：「どの状態からでもゴールへ行ける」「全部のバトラー・宝箱に行ける」・ゴールまでのいちばん少ない切り替えの回数と歩数（階ごと）の表

## 【2】敵を B の子に（ユーザー決定）
- バトラー（npcTeams）と見えない番人（guardianTeam）を、B の子の組み合わせにする：ジオル・ヒョウズク・シシエン・ハクラン・フルーネ から（ギアロスはボスの切り札なので入れない）。例：[ジオル, ヒョウズク, シシエン]／[ハクラン, フルーネ, ジオル]／番人 [ヒョウズク, シシエン, ハクラン]
- **ダンジョンの難しさは今と同じくらいに**：今のままの floorLife で B の子にすると強くなりすぎるので、floorLife を下げて合わせる。目安のプレイヤー（A の枠）でバトラー・番人に勝つ割合を、今（C の子・floorLife 1.1〜1.5）と直したあとで並べた表
- オットーは今のせりふのまま

## 【3】宝箱・報酬
- 宝箱の技カードは、ほかの守り手のダンジョンと同じ形でギアロスの技に（雷の高原と同じ）。今どうなっているか確かめて、違えば合わせる
- 初回クリア＝祭壇でギアロスのモンスターカード・2回目から技カード（今のまま）

## 【4】塔は「上へのぼる」
- 塔なので、階の表示は「1階 → 5階」と上へ（地下ではない）。階段の絵は今の machine_stairs_down。上り階段の絵が無ければ、今の絵をそのまま使って報告（絵は別に頼む）
- 階に入ったときの帯の文も「○階」
