■ 1. カードショップの販売機（店の中だけ。ガチャの画面の機械は変えない）
━━━━━━━━━━━━━━━━━━━━
1. 大きさ：今の約7割にしてください（主人公の背の約1.5倍が目安。棚やカウンターと並べて浮かないように）。置く位置・当たり判定・「調べる」が届く位置・目標の帯との重なりも合わせる
2. 窓の絵：今の 3×2 のパネル（panel_shop）を、panel_shop_group.png 1枚に替える（窓の形に合わせて切り取り・四すみの星の飾りは今のまま上に重ねる。顔が星に隠れないかを確かめる）。panel_shop は「絵の無いシリーズの代わり」にも使われているので、その代わりの絵は今の 3×2 のまま残してかまわない（別の名前にする）
3. 「新入荷」の札（新しい）：
   - 機械の下の左にある四角い板（今は星の羅針盤の飾り）に、**いちばん新しく取れるようになったシリーズのパックの絵**（pack_{id}.webp）を1枚、小さく出す
   - 新しく取れるようになってから、そのシリーズのパックを1回でも開けるまでは「NEW」の光（金の小さな札と、ゆっくりした光。うるさくしない）。開けたら光は消え、パックの絵はそのまま
   - 「いちばん新しい」：シリーズが開いた順の記録が無ければ作る（前のセーブは、今開いているシリーズの GACHA_SERIES の並びの最後を「いちばん新しい」とし、NEW は付けない）
   - 道具のパックは札に出さない。最初から並ぶシリーズしか無いときは、旅立ちの主役（ソラモ）のパックを NEW なしで出す
   - 札の絵は文字を焼きこまない（「NEW」はゲームの文字と飾りで重ねる）
4. 写真：店の中の全体（前と後）・機械のアップ・NEW の札あり／なし・320×568 と 390×844
