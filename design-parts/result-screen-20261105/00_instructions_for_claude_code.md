# 指示書 BG：対戦の結果画面（WIN / LOSE / DRAW）と勝ち・負けの曲（2026-11-05）

公開はしないでください。

## 目的
PS版の結果画面のように、対戦が終わったら「相手の顔＋セリフ」「WIN / LOSE の大きな文字の絵」「主人公の勝ち・負けの絵」を1枚の画面で見せる。
今の結果画面（battleScreen.ts の resultOverlay）を作り直す。今の結果の文字（勝利！／敗北…をゲームが描いている）はチープに見えるので、絵に置き換える。

参考：ref/01（PS版）、ref/09（縦の並びのたたき台。きっちり合わせなくてよい）、ref/02（届いた絵の一覧）。

## 1. 入れる素材
- art/result_win_logo.png・result_lose_logo.png・result_draw_logo.png（各1400×400、背景は透明）
- art/result_opponent_face_frame.png（600×600。中は透明。内側の窓は約500×500で真ん中）
- audio/battle_win_jingle.mp3（勝ち。約9秒）・audio/battle_lose_jingle.mp3（負け。約8秒、最後に約1.4秒の無音）
- いつもどおり webp などに変えてよい。色や形は変えないこと（明るさ・色の調整もしない）。

## 2. 画面の並び（縦。上から）
1. **相手の段**：左に相手の顔（face_frame の中）、右に相手の名前とセリフの窓（今の window_result などの金の枠を使い回す。足りなければ報告）。
   - 顔：今の対戦で使っている相手の顔（opponentFace / personFace）と同じ絵。四角い顔の角が枠の角丸からはみ出さないように切り抜く。
   - セリフ：今、対戦の終わりに出している相手の勝ち・負けのセリフ（people.ts の lines.win / lines.lose、無ければ battle.talk.win / lose）を、この窓に出す。結果画面が出ている間は、対戦中のふきだしには出さない（二重に出さない）。
   - セリフ43名のZIP（先に送ったもの）で勝ち・負けのセリフが変わる場合は、新しいほうを使う。
2. **WIN / LOSE / DRAW の文字の絵**：画面の幅いっぱい近く。今の帯（result_win / result_lose）と組み合わせるか、文字の絵だけにするかは、見て良いほうを選び、両方の写真をください。
   - 文字は日本語版・英語版で同じ絵（英語の WIN / LOSE / DRAW のまま）。
   - 出し方：判子を押すように、少し大きい所から縮んで止まる短い動き（0.3秒くらい）。派手にしすぎない。
3. **主人公の勝ち・負けの絵**（今ある hero_*_win / lose）。
4. **「続ける」ボタン**（今のまま）。下の「◯手番」などの小さい文字も今のまま残してよい。

- 引き分け：DRAW の文字。主人公の絵は今と同じく出さない。
- 顔の絵が無い相手（人ではない相手、見えない番人など）がいるときは、どう出しているかを一覧にして報告してください（ギアロス・タイラントなど）。今は仮に、顔の段ごと出さずにセリフだけ出す形でよい。

## 3. 曲
- 結果画面が出たら、勝ちは battle_win_jingle、負けは battle_lose_jingle を1回だけ流す（くり返さない）。
- 今の2秒の効果音（se/battle_win・battle_lose）は、結果画面では鳴らさない（曲と重ねない）。効果音のファイルは消さなくてよい。
- 対戦のBGMは、結果画面が出たら短く小さくして止めてから曲を流す。
- 曲の途中で「続ける」を押したら、0.3秒くらいで小さくして止める。次の画面の曲と重ねない。
- 引き分けは、今は曲なし（無音）。
- 音量は今のバトルのBGMとほぼ同じ大きさなので、基本はそのまま。音量の設定（オプション）に従うこと。
