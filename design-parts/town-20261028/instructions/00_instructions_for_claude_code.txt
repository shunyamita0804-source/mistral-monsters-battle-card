Claude Code への指示書：街を新しい絵で作り直す（2026-10-28）

■ 目的
街（外）を、デザイン担当が作った新しい部品で作り直す。明るく豊かなファンタジーの街にして、建物の並びも新しくする。
部屋の中（家具・内装）は今のまま。部屋の部品は後日、別の便で届く。
昼夜の切り替えは入れない。

■ 添付するもの
1. Mistral_Town_Part1_Buildings_20261028.zip（建物11・屋台）
2. Mistral_Town_Part2_Terrain_Props_20261028.zip（地面・道のふち・高台・小川・橋・塀と門・噴水・小物・木）
3. この指示書のフォルダ（Mistral_Town_Instructions_20261028.zip）
   - cardshop/：新しいカードショップの外観（建物・左右の自動ドア・座標の JSON・描き方の例・確認画像。ユーザー承認済み）
   - town_layout_numbers.png：配置図（番号つき・北が上）。ユーザー承認済み
   - tools/town_tone_20261028.py：色を落ち着かせる処理（ユーザー承認済み）
   - town_tone_compare_approved.png：承認した色の比較（上＝届いたまま、下＝採用）

ZIP 1・2 と cardshop/ の原本は無改変で design-parts/town-20261028/ に保管する。中の README.txt・asset_manifest.json も読むこと。
シートは「切って使う一覧」で、街の完成図ではない。部品を1つずつ切り出して並べる。

■ 色（大事）
- 新しい部品は、tools/town_tone_20261028.py をかけた写しを使う（原本は変えない。この道具は tools/design/ に置く）
- **今の seimon_world_build.py の TOWN_TONE（あざやかさ×1.18 など）は、新しい部品にかけない。**
  新しい部品はもともと鮮やかで、ユーザーは「1〜2割落ち着かせる」を承認している。TOWN_TONE をかけると元に戻ってしまう
- 建物の落ち影・接地の影（building_shadow・shade_building。光は左上から）は、新しい部品にも今までどおりかけてよい

■ 歩ける所・当たり
- 建物・塀・木・噴水・小川（橋以外）・屋台・高台の壁は通れない

- 入口は扉の正面から入れること

■ 確認と報告
- テストはすべて通すこと
