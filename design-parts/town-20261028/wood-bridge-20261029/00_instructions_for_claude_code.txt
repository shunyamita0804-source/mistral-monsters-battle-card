ミスモンBC｜街の木の橋を正面向きの新しい絵に替える（2026-10-29 夜）

依頼文 docs/design-requests-20261029-night/01_wood_bridge.md の絵が届きました。進行が検品して合格。描き直さない・色を変えない。

■ ファイル
- wood_bridge_front.png（919×1712・本当の透過 PNG）。橋の本体は x 142〜776・y 95〜1600。左右の欄干は上から下まで平行で、中心は x 約460 でずれなし（ななめになっていない）。橋の板は横向き・上下のはしは平らな板

■ やること
1. 原本を design-parts/town-20261028/ に置く（無改変）
2. tools/design/town2026_build.py の木の橋を、deskew なしでこの絵に替える。縦横の比は変えない（同じ倍率）
3. 橋の板の上のはしと下のはしを、北と南の石畳の道に合わせる（段差・すき間なし）。小川は橋の床の下に通す（石の橋と同じやり方）
4. **大きさの注意**：この絵は依頼の目安（横300×縦560）より少し細長い（横：縦＝0.42。目安は 0.54）。小川の幅に長さを合わせると、板の部分が主人公より狭くなるおそれがある。主人公（街の大きさ）を重ねて、板の上を無理なく歩けるかを確かめる
   - 狭いときは、横に合わせて大きくし、長くなった分は両岸の道を少し詰めるか、橋を置く場所の小川の幅に合わせて調整する（絵は切らない・引きのばさない）
   - それでも合わないときは、無理に入れずに報告（絵の描き直しを頼む）
5. 当たり：欄干と柱は歩けない、板の上は歩ける。欄干の柱の前後の重なり（主人公が橋の上にいるとき・下の道にいるとき）

■ 終わったら
npm run check → main に取り込んで公開 → 報告：橋のまわりの前と後の写真（390×844）・当たりの網目を重ねた写真・主人公が橋の真ん中に立った写真
