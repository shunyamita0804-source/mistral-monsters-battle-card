Claude Code への指示書：街の建物7つを正面向きの絵に差し替える（2026-10-28）

■ なぜ
街の道・広場はまっすぐ上から見た形で、移動も上下左右。なのに家など7つの建物が斜め45度を向いていて、ユーザーから「強い違和感」と指摘があった。
大会会場・管理局・研究所・練習場・カードショップと同じ「正面向き（少し上から見下ろして屋根の上が見える）」に描き直してもらった。ユーザー・進行チャットで検品済み。

■ 添付
art/ の7枚（1024×1024・透明 PNG。前と同じファイル名）と確認用の画像・README
- building_home.png（主人公の家）・building_neighbor.png（となりの家）・building_house_pete.png・building_house_harold.png・building_florist.png（花屋）・building_tailor.png（仕立て屋）・building_shed.png（大工の作業小屋）
check_old_top_new_bottom.jpg：上＝今の斜めの絵、下＝新しい正面の絵
原本は無改変で design-parts/town-20261028/ に「front-facing-20261028」として保管（前の斜めの原本も残す）

■ やること
- tools/design/town2026_build.py で、この7つの部品を新しい絵に差し替えて街を作り直す。色の処理（town_tone_20261028.py）・影・光は今のほかの建物と同じ
- 大きさは今までどおり「扉の高さ」でそろえる（主人公より少し高い）
- 扉の位置が変わるので、入口（扉の正面の列）・出たときに戻る場所・当たり（建物の足元の形）を、新しい絵に合わせて置き直す
- 正面向きになって横幅が変わる建物がある。となりの建物・道・小物と重ならないか確かめ、重なるなら建物の位置を少しずらす（配置図の並びは変えない）
- 名前の札（「家」など）の位置も新しい屋根に合わせる
- 住人の立ち位置（ミレイユ＝となりの家の前、ピート＝ショップの前 など）が扉や壁に重ならないか確かめる

■ 確認と報告
- テストはすべて通す
- 画面写真（390×844、街の倍率 0.7）：主人公の家の前／となりの家とピート・ハロルドの家／花屋と仕立て屋／大工の小屋／街の全体（縮小）
- 7つの入口から入って、出ると扉の前に戻ること
- 終わったら main に取り込み、公開して、公開ページでも確かめる。記録を docs/design/town-20261028/ に追記
