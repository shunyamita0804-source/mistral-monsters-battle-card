Claude Code への指示書：お金の入る側（ダンジョンの勝ち・宝箱・ボス）（2026-10-28 ユーザー承認）

■ 0. 順番
- 「カードの見た目 v3」と「手札の大きさ」を公開してから作業する

■ 1. 今の状態（進行が main の fd575a8 で確かめたこと）
- ランダム生成のダンジョン（src/game/dungeon/run.ts の winRunBattle）では、バトラー・見えない番人に勝ってもお金が入らない（coins: 0）。お金が入るのはボスだけ
- ボスのお金は、どのダンジョンも同じ（src/data/economy.ts の REWARDS：初回 200G・2回目から 60G）
- 宝箱は開くだけで、中身がない（openRunChest のコメント「中身は仮でまだ無い」）

■ 2. 決めた数字（すべて「最初の値」。あとで試遊して直すので、ダンジョンごとの表を1か所＝src/data/economy.ts にまとめる）

| ダンジョン | 1勝ごと（バトラー・見えない番人） | 宝箱のお金 | ボス初回 | ボス2回目から |
| --- | --- | --- | --- | --- |
| dungeon-01 太古の遺跡・dungeon-02 精霊の森 | 15G | 15〜30G | 300G | 90G |
| dungeon-03 水の神殿 | 20G | 20〜40G | 500G | 150G |
| dungeon-04 氷の洞窟 | 25G | 25〜50G | 600G | 180G |
| dungeon-05 炎の火山 | 30G | 30〜60G | 700G | 210G |
| dungeon-06 機械の塔 | 35G | 35〜70G | 850G | 250G |
| dungeon-07 天の聖域 | 40G | 40〜80G | 1,000G | 300G |

- 宝箱のお金は、範囲の中から 5G きざみでランダム
- 1勝のお金は、勝ったその場で所持金に入れる（報酬の窓に「＋15G」のように、技カードと一緒に出す）
- 幸運のコインで技カードを選ぶ勝ちでも、お金は同じだけ入る
- ボスのお金は今の REWARDS をこの表に置きかえる（初回のモンスターカードはそのまま）

■ 3. 宝箱の中身（【仮】。1つの宝箱から1つ）
- お金 70％：上の表の範囲
- 道具 25％：たいまつ・魔除けの香・煙玉・帰還の羽根の4つから同じ確率で1つ（所持の上限を超えるときは、お金に替える）
- 技カード 5％：そのダンジョンのボスの切り札のモンスター（初回クリアでもらえるモンスターカードのモンスター）の技カードから1枚
  - 技カードは、勝ってもらった技カードと同じ扱い（この挑戦の獲得に入れる。3回負けて戻されたら失う。封印の小箱で守れる）
- 開けたときの文：「○○G を手に入れた！」「たいまつを手に入れた！」「技カード『○○』を手に入れた！」（技カードはカードの絵も出す）
- 宝箱の中身は開けたときに決める（セーブとロードを繰り返して中身を選び直せないよう、ダンジョンの挑戦の種〔seed〕と宝箱の ID から決める）

■ 4. 変えないこと
- 3回負けて街へ戻されても、お金はなくさない（なくすのは、この挑戦で手に入れた技カードだけ。今の決まりのまま）
- 大会の賞金（E 初優勝 300G … S 1,000G・2回目から半分・C から参加賞 40〜80G）と、はじめの所持金 300G はそのまま
- 固定のダンジョン（src/game/progress/dungeon.ts の defeatEnemy）を今も使っている所があれば、そこも同じ表の値にそろえる。使っていなければ触らない
