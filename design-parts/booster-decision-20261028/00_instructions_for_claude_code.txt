■ 決まったこと
1. **ブースターの箱 ＝ 初期配布**。箱を受け取る・買うと、その箱の中身が手に入る
2. 箱の中身（3種類とも同じ作り）
   - モンスターカード 3枚（その箱の3体）
   - 技カード 48枚 ＝ 3体それぞれの「初期配布16枚」（data/04・05・06。今のコードの INITIAL_DISTRIBUTION と同じ枚数）
   - 仮のサポートカード 12枚（今の createStarterDeckFor と同じ入れ方。正式なサポートカードができるまで仮のまま）
   - 合計：モンスター3体＋山札60枚 ＝ そのまま1つのデッキになる
   | 箱 | モンスター |
   | --- | --- |
   | booster-1 旅立ちのきらめき（バランス） | ソラモ・ガウル・ミュロル |
   | booster-2 烈火の猛攻（攻撃） | ガウル・ラズック・ノビトン |
   | booster-3 蒼海の守り（防御） | カルシェル・ミュロル・ノビトン |
   技の ID は技名で今のデータから引く（data の注意どおり、skl-<monster>-<number> を作らない）
3. **流れ**
   - 新しく始めたとき：主人公を選んだら、そのまま家の始まりへ。**カードは持っていない**（newGameScreen.ts の「初期デッキ3択」の画面はなくす。今の「新しく始めたら初期配布96枚を全部持つ」もやめる）。selectedStarterDeckKey は新しいセーブでは使わない（前のセーブとの互換のためだけに残してよい）
   - 練習場の試験：ガレス先生が貸すデッキで戦う。**貸すデッキは「旅立ちのきらめき」と同じ中身**（ソラモ・ガウル・ミュロル＋その60枚）。試験のあいだだけ使い、所持カードには入れない（試験が終わったら返す。再挑戦のときも同じデッキを貸す）
   - 試験の相手（ガレス先生のデッキ・ライフの倍率）は今の仮のまま
   - チュートリアルの最後：管理局で3箱から1つ選ぶ（今の画面のまま）→ その箱の中身が手に入り、**その60枚＋3体がそのまま使うデッキになる**
   - 選ばなかった2箱：カードショップのカウンターで買える
4. **値段：1箱 1,500G**（仮の 1,000G から変更）。**各箱1回まで**。買ったら棚から消える（または「購入済み」）
5. カードショップのカウンターで買えるのは、**ブースターの箱と道具だけ**。カードはふだんはガチャ（機械）で集める
6. 同じカードが重なっても、そのまま持つ（ガチャと同じ）

7. **欠片の特別復元を研究所へ移す**：今カードショップにある「欠片の特別復元」（隠しモンスターの復元。restoreHidden など）を、ショップから外して研究所に置く。
   研究所の機械（lab_03_machine＝記録の投影機）か実験台（lab_04_lab_counter＝解析台）を調べると、今と同じ復元の画面が出る（どちらにするかは部屋の作りに合わせて Claude Code が決めてよい。研究員ルーカスに話しかけても出せるとよい）。
   復元の条件・画面・絵（restore_scene）は今のまま
8. **大会の総当たり表を「○×」に**（E・D ランクの4人の総当たり）
   - 今の対戦表（勝ち＝金の輪・負け＝えんじの交差線）の記号を、**コードで描く ○ と ×** にする：勝ち＝**青い○**、負け＝**赤い×**、自分どうしのマス＝**斜線1本**。顔・名前・次の相手の光る枠・自分の行の帯は今のまま
   - 大会会場の部屋の**左の壁の紺の大きな板**（部屋4つの指示書で空けておいた所）にも、いま出ている総当たりの大会の表（名前と ○×）を小さく描く。
     大会に出ていないときは、最後に出た E／D の大会の結果。まだ一度も出ていなければ、大会の名前だけ（または空のまま）
   - 板は調べると、対戦表の画面を見られる（受付と同じ表）
   - トーナメント（C〜S）の表は今のまま
